### java Script 기본 문법 ###
```
1. 식별자(변수명) 작성 규칙
    - 반드시 문자, 달러($), 또는 밑줄('_')로 시작

    - 예약어 사용 불가 (for, if 등등)

    - 파스칼 케이스 = 앞글자 대문자 (클래스, 생성자)
    - 대문자 스네이크 케이스 = 다 대문자 + 언더바 활용 (상수에 사용)

        - 재할당 가능 = 값을 다르게
        - 재선언은 불가능 = 동일 이름을 let으로 또 정의하는 형태
          let number = 10 / let number = 20 -> x

    2. const (이거 자주 쓴댕)
        - 블록스코프를 갖는 지역변수를 선언
        - 재할당 불가능 -> 고정값을 갖게 되는!!!!
        - 재선언 불가능 

    * var = 옛날 고대문자/ 존재정도만
    * 선언 시 반드시 초기값 설정 필요!!

4. 블록 스코프
    - if for 함수 등의 중괄호 내부를 가리킴
    - 블록스코프를 가지는 변수는 블록 바깥에서 접근 불가능
```

### javascript 데이터타입 ###
```
1. 원시자료형: 변수에 값이 직접 저장되는 자료형(불변, 값이 복사)
2. 참조자료형: objects (object, array) / 주소값 (속성을 가져오는)

3. number: *NaN = 문자-숫자처럼 값이 안되는 걸 표현
            - 숫자로서 읽을수 없거나 결과가 허수, 정의가 안되는 계산식
            - 피연산자가 NaN 이거나 문자열포함 계산식

4. string:  `~` 백틱 안으로 문자열 집어넣기
            &{expression} -> 변수를 문자와함께 넣을때
5. null: 변수의 값이 없음을 의도적으로 표현할때 사용
6. undefined: 변수 선언 이후 직접 값을 할당하지 않으면 자동으로 할당 #안쓴대요~
    * typeof null // 'object' -> 타입 조심하기
7. Boolean: true, false -> null값을 확인할때
```

### javascript 연산자 ###
```
특이사항들만
*동등연산자(==) 암묵적 타입변환이 일어나서 문자 123과 숫자 123이 동일하다고 뜸
 -> 잘 안쓰게 됨

일치연산자('===')를 그래서 씀!
값과 타입이 모두 같은 경우 true로 변환


not 연산: 앞에 느낌표 (!)
or 연산: ::
and 연산: &&

if 문에서는 추가 의문문 넣을때 else if 형태로!
삼항연산자: (조건) ? true : flase -> 조건이 맞으면 앞에꺼 반환, 아니면 뒤에꺼 반환


반복문
    - while (조건)
    - for (let을 활용해서 변수 초기화; 반복조건; 증가(i++)) {}
      ex: for (let i = 0; i < 6; i++>) {}

    - for ( in ) => 객체 순환해서 진행할 때 (dict)
      ex: for (const property in object){
            console.log(property) // 인덱스 출력
            console.log(object[property]) // 값 출력 
        }
    - for ( of ) => 배열 순환해서 진행할 때
      ex: for (const number of numbers){
            console.log(number) // 배열값 출력 1,2,3,4
          } 
    * const를 in, of에서 쓸때는 변경 불가능하게 지정 
      -> 계속 선언해버려서 여기서만 가능
      -> 추가변수로 let을 써서 변경할때 활용
```
