>API, HTTP, requests
```

http 메서드
- get = 데이터 조회
- post = 데이터 전송
- put = 기존데이터값 변경
- delete = 데이터 삭제


http 상태코드
- 200: 요청성공

        201 = 생성완

- 404: 요청 자원 찾기 불가
        401 = 로그인 님 안함
        403 = 관리자만 볼수 있어요
        404 = 주소를 잘못침

- 500: 서버 내부 오류
        500 = 내가 잘못 만듬

api 키 보안 -> 환경변수 또는 , .env
```
