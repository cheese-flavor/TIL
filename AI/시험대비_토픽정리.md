## 1. CLIP

- **정의**: 대조학습(Contrastive Learning) 기반의 언어-이미지 사전학습 모델. 인터넷의 (이미지, 텍스트) 쌍 데이터를 지도학습처럼 활용해 자연어 기반 시각 개념을 학습.
- **구조**
  - 텍스트 인코더: Transformer(서브워드 단위 임베딩, 토큰 간 관계를 어텐션으로 학습)
  - 이미지 인코더: Vision Transformer 구조 — 이미지를 16×16×3 패치로 분할 → 1D flatten → learnable position embedding 추가 → Transformer encoder 통과 → MLP head
- **대조학습(Contrastive Learning)의 목표**: 매칭되는 (이미지, 텍스트) 쌍은 임베딩 공간에서 가깝게, 매칭되지 않는 쌍은 멀게 배치 → 의미 기반 "거리 감각" 학습
- **관련/파생 모델**
  - **SigLIP**: softmax 대신 sigmoid 기반 손실. CLIP은 이미 충분히 먼 음성(negative) 쌍도 계속 밀어내려 학습하는 비효율이 있는데, SigLIP은 이런 음성쌍의 영향을 제한적으로만 반영하도록 설계
  - **ImageBind**: 이미지·비디오 등 여러 모달리티가 공유하는 임베딩 공간을 학습(멀티모달 정합)

## 2. CLIP Zero-shot 분류

제로샷 이미지 인식기의 절차:
1. 분류하고 싶은 카테고리들을 자연어 텍스트 리스트로 준비 (예: "a photo of a {class}")
2. 텍스트 인코더로 각 카테고리 텍스트를 임베딩 벡터로 변환
3. 쿼리 이미지를 이미지 인코더로 임베딩
4. 이미지 임베딩과 각 카테고리 텍스트 임베딩 간 유사도(코사인 유사도 등) 계산
5. 가장 높은 유사도 점수를 가진 카테고리를 예측 라벨로 반환

- **핵심 포인트**: 별도의 fine-tuning 없이, 사전학습만으로 새로운 카테고리(학습 시 보지 못한 클래스)를 분류 가능 → CLIP의 대조학습이 만든 공유 임베딩 공간 덕분.

## 3. CNN 공간 구조

- 합성곱 레이어는 입력 이미지의 **3차원 구조(높이×너비×채널)를 그대로 보존**하면서 연산 수행 (FC층처럼 flatten 하지 않음)
- 필터(커널)는 항상 **입력의 채널(깊이) 축과 동일한 차원**을 가짐 (예: 입력이 3채널이면 필터도 3채널)
- 연산: 필터가 이미지를 이동(slide)하며 내적(dot product) 수행 → WᵀX + b
- 필터가 이동한 경로에서 나온 모든 값을 모아 하나의 **활성화 맵(feature map)** 생성
- 특징: 지역적 특징 추출에 특화, **가중치 공유**로 파라미터 효율적, 위치 변화·노이즈에 상대적으로 견고
- **수용영역(Receptive Field)**: 한 뉴런이 원본 입력에서 실제로 보고 있는 영역 크기. 레이어를 깊게 쌓을수록 수용영역이 넓어짐 → 지역 정보 + 전역 맥락을 함께 파악하기 위한 설계

## 4. CNN 출력 크기 계산

기본 공식(패딩 없을 때):

```
출력 해상도 = 입력 해상도 - 필터 해상도 + 1
```

패딩(P), 스트라이드(S)를 포함한 일반식:

```
W' = (W - K + 2P) / S + 1
```
- W: 입력 크기, K: 커널(필터) 크기, P: 패딩, S: 스트라이드

- 입출력 해상도를 **동일하게 유지**하고 싶으면 패딩을 적용해서 필터가 이미지 밖으로 나가는 영역을 0(zero-padding) 또는 가장 가까운 값으로 채움
- **출력 채널 수 = 현재 레이어의 필터 개수** (해상도 공식과 별개로, 채널 수는 필터 개수로 결정됨)
- **출력 메모리 사용량** ≈ 출력채널 수 × 출력 해상도(H) × 출력 해상도(W)
- 스트라이드 합성곱(strided convolution): 필터를 1칸이 아니라 S칸씩 이동 → 풀링과 유사하게 해상도를 줄이면서 학습 가능한 파라미터도 가짐 → 풀링+합성곱을 한 레이어로 대체하는 최근 경향

## 5. CNN 파라미터 수 계산

```
파라미터 수(K) = 출력채널수 × 입력채널수 × (커널크기)² + 출력채널수(bias)
```

- 마지막 `+ 출력채널수`는 각 출력 채널마다 붙는 bias 항
- 연산량(FLOPs) ≈ 출력 원소 수 × 원소별 연산량 (파라미터 수와는 별개 지표이니 혼동 주의)
- 예: 3×3 커널, 입력 64채널 → 출력 128채널이면
  `K = 128 × 64 × (3×3) + 128 = 73,856`

## 6. CNN과 ViT

| 구분 | CNN | ViT |
|---|---|---|
| 전역 맥락 파악 방식 | 레이어를 깊게 쌓아 수용영역을 점진적으로 확장 | 첫 레이어부터 어텐션으로 전역 관계 직접 학습 (수용영역 개념 자체가 필요 없음) |
| 귀납적 편향(inductive bias) | 지역성·위치불변성 내장 → 적은 데이터에서도 학습 잘 됨 | 편향이 거의 없음 → 대규모 데이터/학습 자원 필요 |
| 순서/위치 정보 | 합성곱 구조 자체에 내재 | 위치 인코딩(positional encoding)을 명시적으로 추가해야 함 |
| 소규모 데이터 성능 | 상대적으로 강함 | 데이터 적으면 CNN보다 성능 저하 |
| 활용 | 이미지 분류/탐지의 표준, 파라미터 효율적 | 분류/탐지/분할/생성 모두 SOTA권, 멀티모달 아키텍처에 유리 |

- CNN의 핵심 한계(→ ViT/어텐션이 보완): 데이터 순서 반영 어려움, 멀리 떨어진 요소 간 장거리 의존성 학습 부족, 압축 과정에서 위치 정보 손실
- **Knowledge Distillation과의 접점**: ViT는 파라미터가 매우 많아 정규화·증강이 중요한데, 증류학습(선생 CNN/ViT → 학생 ViT)을 적용하면 학습 효율이 좋아짐

## 7. Deep Network

- Shallow 네트워크(입력층-은닉층 1개-출력층)도 hidden unit이 충분히 많으면 임의의 1차원 함수를 원하는 정확도로 근사 가능 (보편 근사 정리 관점)
- 그러나 **Deep 네트워크(은닉층 여러 개)가 표현력이 더 높음** — 같은 파라미터 수라도 층을 깊게 쌓는 편이 복잡한 함수를 더 효율적으로 표현
- 모수(parameter)가 정해지면 특정 함수(모델)가 하나로 결정되고, 이를 이용해 추론 가능
- 각 파라미터는 "출발 노드 값 × 가중치"를 다음 노드에 더하는 형태로 작동 → 입력 구간을 여러 조각으로 나눠 조각별 선형 함수(piecewise linear)를 만드는 것과 유사한 직관

## 8. Diffusion 이미지 생성

*(강의자료에 상세 언급이 얕아 일반 개념으로 보충)*

- **Forward process(정방향, 노이즈 추가)**: 원본 이미지에 여러 단계(timestep)에 걸쳐 점진적으로 가우시안 노이즈를 주입 → 최종적으로 순수 노이즈에 가까운 분포로 변환
- **Reverse process(역방향, 노이즈 제거)**: 신경망(주로 U-Net 구조)이 각 timestep에서 "현재 이미지에 추가된 노이즈가 무엇인지"를 예측하도록 학습 → 학습된 모델로 순수 노이즈에서 시작해 단계적으로 노이즈를 제거하며 이미지를 생성
- **학습 목표**: 각 timestep t에서 실제로 추가된 노이즈와 모델이 예측한 노이즈 간의 차이(보통 MSE)를 최소화
- **조건부 생성(text-to-image)**: 텍스트 프롬프트를 임베딩(CLIP 텍스트 인코더 등)해 U-Net에 조건으로 주입 → cross-attention 등으로 텍스트 정보를 반영하며 디노이징
- Stable Diffusion류는 픽셀 공간이 아니라 **latent space(잠재 공간)**에서 diffusion을 수행해 연산량을 줄임(오토인코더로 압축된 latent에 노이즈 추가/제거)

## 9. LLM 안전 정렬

- **정렬학습(Alignment)의 목표**: 거대 언어모델의 출력이 사용자의 의도와 가치를 반영하도록 만드는 것
- 정렬학습의 두 축:
  1. **지시학습(Instruction tuning)**: 주어진 지시에 대해 "어떤 응답이 생성되어야 하는가"를 학습
  2. **선호학습(Preference learning)**: 여러 후보 응답 중 "상대적으로 어떤 응답이 더 선호되는가"를 학습
- **배경**: GPT-3류 모델은 다음 토큰 예측만으로 학습되어 있어, 질문에 제대로 응답을 못하거나 유해한 답변을 생성하는 문제가 있었음 → 이를 보완하기 위해 정렬학습 도입
- **탈옥(Jailbreak)**: 프롬프트 엔지니어링을 통해 모델의 정렬(안전장치)을 우회하는 시도. 여러 단계의 학습 과정 자체에서 비롯된 근본적 한계이며, 다양한 방어 기법이 계속 연구되는 중
- **환각(Hallucination)**: 사실과 다르거나 지어낸 내용을 정확한 정보와 동일한 자신감으로 생성 → 확률적 다음 토큰 예측 방식 자체의 한계, 사용자가 진위를 구별하기 어렵다는 점에서 안전 이슈로 연결됨

## 10. LSTM 게이트

LSTM은 RNN의 hidden state에 더해 **cell state**(장기 기억 저장용)를 추가로 가짐.

| 게이트 | 역할 |
|---|---|
| **Forget gate (망각게이트)** | 이전 cell state에서 무엇을 버리고 무엇을 유지할지 결정 |
| **Input gate (입력게이트)** | 새로운 정보 중 얼마나 cell state에 반영(기록)할지 결정 |
| **Output gate (출력게이트)** | cell state 중 얼마나 hidden state로 내보낼지 결정 |

- 각 게이트는 매 시점 **동적으로 계산**됨 (현재 입력 + 이전 hidden state 문맥에 따라 값이 정해짐)
- 게이트에 **시그모이드**를 쓰는 이유: 0~1 사이 값으로 "흐름을 조절"하기 적합
  - 0 → 완전히 닫음(정보 차단) / 1 → 완전히 열음(전부 통과) / 0.5 → 절반만 통과
- 셀 상태는 기울기를 곱셈이 아니라 **덧셈 형태**로 전달 → 단순 RNN 대비 기울기 소실 문제를 크게 완화(장기 보존)
- 한계: 입력값에 대해 출력값이 1개만 나옴 / 망각게이트가 과거 정보를 조금씩 계속 줄여나가므로 결국 장기적으로는 정보 희석(악화) 문제 존재

## 11. p-value 해석

- 회귀 계수의 **유의성 검정**: 계수의 p-value가 매우 작으면(예: p < 0.0001 ≪ 0.05) 해당 변수가 **통계적으로 유의**하다고 판단 → 즉, 그 계수가 0이 아닐 가능성이 높다는 뜻
- **t-statistic**: 두 집단 간 평균 차이가 표본의 변동성(분산) 대비 얼마나 큰지를 나타내는 값. t-값이 클수록 그 차이가 통계적으로 유의할 가능성이 커짐 → p-value는 이 t-statistic으로부터 계산됨
- 일반적 기준: p-value < 0.05면 통계적으로 유의하다고 판단(귀무가설 기각)
- 주의: p-value가 작다고 해서 **효과 크기가 크다는 뜻은 아님** — 유의성과 실질적 중요도는 별개 개념

## 12. ReLU

```
f(x) = max(0, x)
```

- 입력이 음수면 0, 양수면 그대로 출력
- **장점**
  - 양의 영역에서 포화(saturation)되지 않음 → sigmoid/tanh 대비 기울기 소실 문제가 크게 줄어듦
  - 계산이 단순한 max 연산이라 계산 효율성이 높음 (exp 연산 없음)
  - 학습 속도가 빠름 (sigmoid/tanh 대비 실측 약 6배 빠른 수렴)
- **단점**: **죽은 뉴런(dead neuron) 문제** — 입력이 계속 음수로 들어오면 해당 뉴런이 영구적으로 0만 출력하게 됨(기울기도 0이라 회복 불가), 0을 기준으로 비대칭적인 출력
- **개선 버전**
  - **Leaky ReLU**: `f(x) = max(0.01x, x)` — 음수 영역에도 작은 기울기를 부여해 죽은 뉴런 문제 해결. 단, 0.01이라는 값의 임의성, 0 중심 비대칭 문제는 남음
  - **ELU**: x>0이면 x, x≤0이면 `a(exp(x)-1)` — 평균 출력이 0 근처, 음수 영역에서도 포화구간을 둬서 기울기 소실과 왜곡 문제 동시 해결. 단, 계산 복잡도 증가 + 하이퍼파라미터 a 설정 필요

## 13. RLHF 학습 절차

InstructGPT(→ LLaMA2 등도 동일 방식 채택) 기준 3단계:

1. **지시학습(SFT, Supervised Fine-Tuning)**: 사람이 작성한 (지시, 응답) 예시로 파운데이션 모델을 추가학습
2. **보상 모델(Reward Model) 학습**: 사람의 선호를 모방하도록 학습된 모델. 여러 응답 후보에 대해 사람이 매긴 선호 순위 데이터로, "사람이 선호하는 형태"를 점수화할 수 있게 학습
3. **강화학습 단계(자가발전/PPO 등)**: 보상모델이 준 보상값을 기준으로 언어모델이 스스로 정책을 개선(모델이 생성 → 보상모델 채점 → 정책 업데이트를 반복)

- 배경: 지시학습만으로는 "개방형 태스크"에서 하나의 정답만 있다고 가정하는 한계가 있음 → 사람이 상대적으로 더 선호하는 응답을 학습시키기 위해 선호학습(RLHF) 도입

## 14. Seq2Seq와 Transformer

**Seq2Seq**
- 입력과 출력의 길이가 달라질 수 있는 문제(번역 등)를 다루기 위해 고안. 2개의 LSTM(Encoder/Decoder) 사용
- **Encoder**: 입력 문장의 정보를 Context Vector로 인코딩
- **Decoder**: Context Vector를 조건으로 타겟 문장 생성
- **Teacher Forcing**: 학습 초반 모델의 예측이 불안정하므로, 모델이 직접 예측한 단어 대신 정답 토큰을 다음 스텝 입력으로 강제 주입해 학습 안정성/성능 향상
- **한계 (Bottleneck problem)**: 문장 길이와 무관하게 Context Vector 크기가 고정 → 문장이 길어질수록 초반 정보가 희석/손실되어 번역 품질 저하 (장기 의존성 문제)
- 이 한계를 해결하려는 시도가 **Attention** (디코더가 매 시점 인코더의 여러 부분을 다시 참조)

**Transformer**
- Encoder-Decoder 구조의 신경망. RNN/LSTM 없이 **어텐션만으로 시퀀스를 처리** → 병렬화 가능, 장거리 의존성 문제 해결
- **Encoder**: 입력을 양방향 문맥으로 처리(마스킹 없음), 의미적 표현으로 변환
- **Decoder**: 단방향(마스킹된) self-attention + **cross-attention**(query는 decoder, key/value는 encoder에서) + FFN, 각 서브층마다 residual connection + layer normalization(Add & Norm)
- **Residual connection**: 층이 깊어져도 학습이 어려워지지 않도록, 입력과 출력의 "차이"만 학습하게 함
- **Layer normalization**: 층이 깊어질수록 불안정해지는 hidden 값들을 정규화해 학습 안정성/속도 확보

| | Seq2Seq(LSTM 기반) | Transformer |
|---|---|---|
| 순차 처리 | 시점마다 순차적으로 처리(병렬화 불가) | 어텐션으로 한 번에 모든 위치 처리(병렬화 가능) |
| 장거리 의존성 | 멀어질수록 정보 손실(bottleneck) | self-attention으로 모든 단어가 직접 상호작용 |
| 정보 전달 | 고정 크기 Context Vector 1개 | 매 시점 동적으로 계산된 attention 가중합 |

## 15. Top-K, Top-P 샘플링

디코딩(토큰 생성) 알고리즘 비교:

| 방법 | 설명 | 장점 | 단점 |
|---|---|---|---|
| Greedy | 매 단계 확률 최고 토큰 선택 | 사용성 높음, 빠름 | 근시안적 선택 → 전체적으로 최선이 아닐 수 있음, 되돌리기 불가 |
| Beam Search | 매 단계 k개 유망 후보를 동시 유지, EOS 도달 시 후보로 등록, 최종적으로 누적 로그확률 합으로 선택 | 좋은 응답 생성 확률 높음 | 후보 수만큼 계산량 증가 |
| Sampling | 모델이 준 확률분포에서 무작위 샘플링 | 다양성 확보 | 품질 저하 가능 |
| Temperature Sampling | 온도 t로 확률분포 모양 조작 | 창의성/안정성 조절 가능 | t<1이면 다양성↓, t>1이면 품질 불안정 |
| **Top-K Sampling** | 확률 상위 K개 토큰 중에서만 랜덤 샘플링 | 품질 낮은(가능성 낮은) 토큰을 미리 배제 | K가 고정값이라 분포 모양과 무관하게 항상 같은 개수만 고려 |
| **Top-P Sampling (nucleus)** | K를 고정하지 않고, 누적확률이 p가 될 때까지의 토큰 집합에서 샘플링(K가 상황에 따라 자동 조절) | 확률 분포 모양에 맞춰 품질-다양성 균형 유지 | 적절한 p값 설정이 필요 |

- 핵심 차이: Top-K는 "후보 개수"를 고정, Top-P는 "누적 확률 질량"을 고정 → 분포가 뾰족할 때/평평할 때 모두 유연하게 대응 가능한 쪽이 Top-P

## 16. 개방형과 폐쇄형 LLM

- **개방형(Open) LLM**
  - 장점: 무료로 다운로드 가능, 가중치/구조 등 정보 공개, (계산 자원만 있다면) 자유로운 커스터마이징 가능
  - 상대적으로 폐쇄형 대비 투명성이 높음
- **폐쇄형(Closed) LLM**: API 등을 통해서만 접근, 내부 구조/가중치 비공개(강의자료 기준 개방형의 반대 개념으로 대비되어 설명됨)
- 실무적 트레이드오프로 자주 언급되는 축: 커스터마이징 자유도·비용 vs. 상업적 지원·최신 성능/안전장치의 완성도 (강의자료 원문에는 폐쇄형 장단점이 상세히 적혀있지 않으므로 원자료 재확인 권장)

## 17. 결정계수 R²

- **정의**: Label(반응변수)의 분산 중 피처(설명변수)로 설명되는 비율
- **해석**: 0~1 사이 값을 가지며, 1에 가까울수록(%로 표현 시 설명 가능성이 높을수록) 모델이 데이터를 잘 설명
- **용도**: 모델 성능을 직관적으로 비교할 때 사용되는 회귀 설명력 지표
- 다중선형회귀에서 주의점: R²만으로 테스트 성능을 판단하면 과적합으로 인해 실제보다 성능이 좋아 보일 수 있음 → 반드시 검증/교차검증과 함께 확인

## 18. 경사하강법

- 손실함수 `L[θ]`: 파라미터 θ를 입력받아, 예측이 실제와 얼마나 다른지를 스칼라로 반환하는 함수
- 목표: `θ̂ = argmin L[θ]` — 손실을 최소로 만드는 파라미터를 찾는 것
- **절차**
  1. 기울기 계산: 손실함수를 파라미터에 대해 편미분(벡터 형태의 gradient)
  2. 파라미터 업데이트: 기울기의 **반대 방향**으로 이동해야 손실이 줄어듦
- **Convex vs Non-convex**
  - Convex(볼록): 2차 미분이 항상 0 이상, U자형 → 전역 최소값이 유일 → 최적화가 쉬움
  - Non-convex(비볼록): 봉우리/골짜기가 섞임 → 여러 지역 최소값·안장점 존재 → 최적화가 어려움
- **경사하강법의 단점**: Non-convex에서 지역 최소점에 빠지기 쉬움 / 매 스텝마다 전체 데이터에 대한 미분 계산 필요 → 계산량이 큼
- **확률적 경사하강법(SGD)**
  - 전체 데이터 대신 무작위로 선택한 일부(미니배치)로 기울기 계산
  - 경로에 무작위성(노이즈)이 생기고, 이 노이즈 덕분에 오히려 지역 최소점에서 벗어나기 쉬움
  - 노이즈가 있어도 평균적으로는 올바른 방향으로 수렴
  - 계산비용이 절감되어 큰 데이터셋에서 효율적
  - 단, convex 문제에서는 정확한 경사하강법보다 수렴이 늦을 수 있음

## 19. 데이터 증강

*(강의자료에 명시적 절 없이 ViT 관련 언급 위주 → 개념 보충)*

- 강의자료 언급: **ViT는 파라미터가 막대해서** 정규화 기법과 **데이터 증강이 특히 중요**하다고 명시됨 (일반화 성능 확보를 위해)
- 목적: 제한된 학습 데이터에서 인위적으로 변형된 샘플을 추가 생성해, 모델이 더 다양한 변형(위치, 각도, 조명 등)에 강건해지도록 만들고 과적합을 줄이는 기법
- 이미지 도메인 일반적 기법: 좌우반전(flip), 회전(rotation), 크롭(crop), 색상/밝기 변형(color jitter), Cutout/Mixup/CutMix 등
- 관련 원칙(모델별 전처리): AlexNet(평균 이미지 빼기), VGG(채널별 평균 빼기), ResNet(평균 빼기 + 채널별 표준편차 나누기) — 데이터 형식/조건은 학습·검증·테스트에 **동일하게** 적용해야 함

## 20. 로지스틱회귀의 변환

- **배경 문제**: 선형회귀는 예측 확률이 0보다 작거나 1보다 클 수 있어 분류 문제에 부적절
- **시그모이드 함수**로 이를 해결: `y = e^z / (1 + e^z)` → 출력값을 0과 1 사이(끝점 포함)로 제한 → 확률로 해석 가능
- **오즈(Odds)**: 성공(y=1) 확률이 실패(y=0) 확률에 비해 몇 배 더 높은가를 나타내는 비율
- **로짓 변환(logit)**: 오즈에 로그를 취한 것(log-odds) → 선형회귀의 우변(B0+B1X)과 이 로짓이 같아지도록 모델링하는 것이 로지스틱 회귀의 핵심 아이디어
- **우도(Likelihood)**: 현재 확률함수(모델)가 관측 데이터를 얼마나 잘 설명하는지 나타내는 지표
  - 학습 목표: 우도를 최대화 → **MLE(최대우도추정)**
  - 계수에 대한 미분이 어려워, 양변에 log를 취해 곱셈을 덧셈으로 바꾼 뒤(log-likelihood) 최대화
  - 도함수 = 0에 가까워지도록 수치적 최적화 수행

## 21. 멀티-헤드 어텐션

- **아이디어**: 여러 개의 서로 다른 헤드(head)가 **병렬로** self-attention을 수행 → "같은 문장을 여러 전문가가 각기 다른 관점(문맥, 시제, 명사 등)에서 동시에 분석한 뒤 의견을 종합"하는 것과 유사
- 단일 self-attention은 한 가지 관점만 학습 가능 → 멀티헤드로 다양한 관점 확보
- **중요 포인트**: 각 헤드가 실제로 "무엇에" 주목할지는 사람이 미리 지정하지 않으며, 학습 과정에서 자연스럽게 드러남(emergent)
- ViT에서도 동일 개념 적용 — 인코더 내부에 다중헤드 어텐션이 있어 여러 관점에서 패치 간 관계를 학습

## 22. 선호 학습

- **배경**: 지시학습은 "주어진 입력에 대해 적절한 하나의 정답 응답이 있다"고 가정 → 정답이 여러 개일 수 있는 개방형 태스크에서는 한계
- **정의**: 다양한 응답 후보 중 사람이 더 선호하는 응답을 생성하도록 추가 학습. 선호도는 사람이 직접 제공(품질과 안전성을 모두 반영하기 위함)
- **ChatGPT**: GPT 구조에 채팅(대화) 데이터를 결합한 형태
- **InstructGPT (RLHF 기반)**
  1. 지시학습을 통한 파운데이션 모델 추가학습
  2. 보상모델: 사람의 선호를 모방하는 모델 학습
  3. 자가발전(강화학습) 단계: 보상값에 따라 스스로 피드백하며 정책 개선

## 23. 셀프-어텐션

**NLP 관점**
- 장기 의존성을 효율적으로 포착하고 **병렬처리**를 가능하게 하는 메커니즘
- RNN의 한계(순차성으로 인한 병렬화 불가, 시퀀스 길이만큼 단계를 거쳐야 하는 장기 의존성 문제)를 해결
- 각 단어 i를 Query, Key, Value 벡터로 표현
  - Query: 단어 i가 다른 단어로부터 어떤 정보를 찾을지 정의
  - Key: 단어 i가 자신이 가진 정보의 특성을 표현
  - Value: 실제로 참조되는 정보 내용
- 장점: 순차 처리 단계 수가 시퀀스 길이에 비례해 늘지 않음 / 최대 상호작용 거리가 O(1) — 모든 단어가 각 층에서 직접 상호작용
- **한계와 보완**
  - 순서 정보 부재 → **Positional Encoding** 추가 (sinusoidal 또는 학습형 절대 위치 임베딩)
  - 비선형성 부족(가중평균은 선형 결합) → **Feed-Forward Network** 추가
  - 미래 단어 참조 문제 → **Masked Self-Attention**(미래 위치 점수를 -∞로 설정)
- **Scaled Dot-Product**: Q·K 내적 후 √(차원)으로 나눠 스케일링 → softmax가 한쪽으로 쏠리며 발생하는 기울기 소실 방지

**Vision(ViT) 관점**
- 하나의 이미지 안에서 패치 간 (Q, K, V)를 정의해 같은 이미지 내 패치 유사도를 반영
- 입력 내부 패치 간 연결망을 구축 → 비슷한 패치끼리 묶이는 클러스터링과 유사한 효과
- **교차 어텐션(cross-attention)**과 구분: self-attention은 하나의 입력 내부, cross-attention은 서로 다른(이종) 데이터 간에 Q/K/V를 정의

## 24. 어텐션

- **핵심 아이디어**: 디코더(또는 쿼리 위치)가 매 시점 인코더(또는 전체 시퀀스)의 특정 부분을 다시 참조할 수 있다면? → 고정된 하나의 context vector 대신, 매 시점마다 다른 가중치로 조합된 context vector를 새로 생성
- **동작 절차**
  1. Score 계산: query와 key 간 유사도 계산
  2. Softmax 가중 변환: score를 0~1 사이 확률처럼 정규화
  3. 가중합: 정규화된 가중치로 value들을 섞어 최종 결과 생성
- **효과**
  - NMT(신경망 기계번역) 성능 향상(필요한 부분에만 집중)
  - Seq2Seq의 bottleneck 문제 해결(긴 시퀀스 정보손실 방지)
  - 기울기 소실 완화(멀리 떨어진 단어도 직접 연결)
  - 해석 가능성 제공(어디에 주목했는지로 번역 품질 확인 가능)
  - 정렬(alignment): 단어-단어 간 매핑 관계를 자연스럽게 학습
- Vision에서는 픽셀 거리와 무관하게, 이미지 내 유사한 패치들을 서로 연결해 관련도가 높은 패치 정보를 최종 결정에 반영

## 25. 언어모델

- **정의**: 인간 두뇌가 자연어를 생성하는 능력을 모방 → 단어 시퀀스 전체에 확률을 부여해 문장의 "자연스러움"을 평가
- 한 문장의 확률 = 각 단어의 **조건부 확률들의 곱**으로 표현 가능
- **n-gram**: 연속된 n개 단어 묶음의 등장 빈도를 바탕으로 다음 단어를 예측하는 전통적 방식
- **Bayes rule 활용(번역)**: 식을 번역모델과 언어모델 두 부분으로 분리 — 단어/구가 어떻게 번역돼야 하는지(번역모델) + 얼마나 유창한 표현인지(언어모델)
- 전통적 언어모델의 단점: 구조적 복잡성, 많은 수작업이 필요해 유지·확장이 어려움
- 현대적 확장: 사전학습된 언어모델은 파라미터 초기화 관점에서 효과적이며, 학습된 확률분포를 통해 텍스트 샘플링/생성이 가능

## 26. 오버피팅과 분포 변화

- **오버피팅(과적합)**: 훈련 데이터의 우연한 패턴/잡음까지 학습해 훈련 시에만 성능이 좋은 상태
  - 표본 의존 불안정성: 샘플에 따라 예측이 크게 흔들림
  - 일반화 실패: 보지 못한 데이터에서 오류가 커짐
  - 원인: 모델이 너무 복잡해서 오류(노이즈)까지 학습
- **언더피팅(과소적합)**: 모델이 너무 단순해서 중요한 패턴조차 놓치는 상태
- **훈련오류 vs 테스트오류**
  - 훈련오류: 학습에 쓴 데이터로 다시 계산한 오류
  - 테스트오류: 학습에 쓰지 않은 새 데이터에 대한 평균 예측오류
  - 오버피팅 = 훈련오류 낮음 + 테스트오류 높음 / 언더피팅 = 둘 다 높음(학습 부족)
- **분포 변화(distribution shift)와의 관계**: 테스트 데이터가 훈련 데이터와 다른 분포를 가지면(실제 새 관측치), 오버피팅된 모델일수록 테스트 성능 저하가 더 크게 나타남 → 검증셋/교차검증으로 일반화 성능을 사전에 가늠
- **k-fold 교차검증**: 테스트 오류 추정의 표준 접근. k=n이면 LOOCV(Leave-One-Out) — 연산량 대비 성능 향상이 크지 않아 일반적으로 k-fold를 더 추천

## 27. 온디바이스 VLM

- **MobileNet**: 모바일/임베디드 환경 구동을 목표로, 공간(깊이별 합성곱)과 채널(1×1 화소별 합성곱) 처리를 분리 → 기존 대비 연산량 약 9배 절감, 파라미터 대폭 감소. 이후 효율형 모델 구조(깊이별 합성곱, 보틀넥)의 표준을 제시
- **경량 VLM 계열(Qwen-VL 시리즈, 알리바바)**
  - Qwen-VL: 텍스트 LLM + 시각처리 능력. 사전학습 2단계 + 명령어 파인튜닝, 시각 인코더/어댑터 중심 최적화
  - Qwen2-VL: 다국어 텍스트, 임의 해상도 이미지 처리 / Multimodal Rotary Position Embedding(1D 텍스트, 2D 시각, 3D 비디오 위치정보)
  - Qwen2.5-VL: 문서 파싱, 정밀 객체 그라운딩, 장시간 비디오 이해 강화
  - Qwen2.5-Omni: 텍스트/이미지/오디오 등을 모두 다루는 Omni(전부) 모델
- **한국어(온디바이스) sVLM 이슈**: 언어별 토큰 길이 격차(토큰 정보밀도 차이) — 영어 중심 토크나이저는 동일한 문장이라도 다른 언어보다 토큰 수가 최대 2.5배까지 적어질 수 있어, 비영어권 언어에는 구조적 불이익이 존재(같은 max token 한도 내에서 담을 수 있는 정보량이 줄어듦 → 온디바이스처럼 자원이 제한적인 환경일수록 이 격차가 더 크게 문제됨)

## 28. 지도학습의 목적

- **정의**: 정답 라벨이 있는 훈련 데이터를 사용해 예측 모델을 학습 → 목표는 **새로운(보지 못한) 데이터에서 정확한 예측 수행**
- 구성 요소: 특성(x, 예측에 쓰이는 설명변수) / 라벨(y, 맞춰야 하는 정답) / 오류(예측값-라벨의 차이)
- **손실함수**로 오류를 정량화하고, 학습을 통해 이를 줄여나감
  - 분류: 교차엔트로피 (정답 범주에 얼마나 확률을 부여했는지 기반)
  - 회귀: MSE (많이 틀릴수록 손실이 커짐)
- 평가지표
  - 회귀: R²(설명력)
  - 분류: 정확도(불균형 데이터에서는 주의), 혼동행렬(TP/TN/FP/FN), 정밀도/재현율/F1-score
- 핵심 목표는 훈련 데이터 자체를 완벽히 맞추는 것이 아니라 **일반화(generalization)** — 새 데이터에 대한 예측 성능

## 29. 지시 학습

- **FLAN 관점의 핵심**: "무엇을 목표로 학습하는가"가 중요 — 번역용, 감정분석용처럼 개별 특정 모델을 만드는 게 아니라, **모든 태스크를 텍스트 기반 지시-응답 형태로 표현**해 하나의 모델을 동시다발적으로 학습
- 아이디어: 지시(instruction)를 이해하는 능력 자체를 메타적으로 학습하면, 새로운 태스크도 지시만 이해하면 수행 가능하지 않을까 하는 접근
- 방법: 기존 NLP 태스크 데이터를 지시학습용 형태로 변환해 학습·테스트에 활용. 이때 학습에서 보지 못한 지시에 대한 **일반화 성능**을 평가하기 위해, 관련 없는(held-out) 태스크들을 별도 테스트셋으로 구성
- **모델 크기 의존성**: 일정 규모 이하에서는 지시학습 효과가 떨어짐 — 충분히 커야만 "지시에 대한 응답" 능력이 창발(emergent)함
- 지시를 주는 방법으로는 사람에게 대화하듯 **자연어로 지시**하는 것이 가장 효과적

## 30. 참 함수와 측정오차

- 1D 피처 기반 학습 예시: `Income = f*(X) + E`
  - **f\*(참 함수)**: 우리가 알지 못하는, 데이터를 생성한 진짜 관계식
  - **E(측정오차/잡음)**: 관측 과정에서 발생하는 오차, 모델이 설명하지 못하는 부분
  - `Y = f*(X) + E` 형태로 표현
- **f(x)를 학습(추정)하는 이유**
  1. 예측: 새로운 X에 대한 Y 예측
  2. 중요 특성 파악: 어떤 피처가 예측에 크게 기여하는지 이해
  3. 해석 가능성: 관계 자체를 사람이 이해할 수 있게 하는 것
- 다중선형회귀에서 오차(잔차)는 "모델이 설명하지 못하는 부분"이며, 참 함수 f\* 자체는 알 수 없기에 f̂(추정 함수)로 근사

## 31. 클러스터링과 표준화

- **클러스터링의 목표**: 서로 유사한 데이터는 같은 그룹, 그룹 간에는 상이하도록 데이터를 분할. "유사/상이"의 기준은 문제 도메인에 따라 다름
- **좋은 군집화**: 클러스터 내부 변동(거리 합)이 최소가 되도록 나눈 분할
- **K-means**: K를 미리 정함 → (1) 초기 무작위 클러스터 할당(여러 번 시도 권장) → (2) 중심 계산 후 관측치를 가장 가까운 중심으로 재할당 반복. 매 반복 손실은 감소하지만, 초기값에 따라 **지역 최솟값**으로 수렴할 수 있어 항상 전역 최적해를 보장하지 않음
- **계층적 군집**: K를 사전에 고정하지 않고, 덴드로그램으로 전체 병합 구조를 제공. Single/Complete/Average 링크 방식으로 클러스터 간 거리를 정의
- **⭐ 표준화(스케일링)의 중요성**: 클러스터링 시 **변수 단위 차이의 영향이 매우 크므로 스케일링은 필수** — 단위가 큰 변수가 거리 계산을 지배해버리면 실제로 중요한 다른 변수의 영향력이 왜곡됨
- 클러스터 개수 선정: 정답이 정해져 있지 않으므로 여러 번의 시도를 통해 적합한 개수를 탐색

## 32. 파인튜닝

- **일반 정의**: 사전학습(pretraining)된 모델의 파라미터를 초기값으로 삼아, 특정 다운스트림 태스크/데이터에 맞춰 추가로 학습을 진행하는 것 → 처음부터 학습하는 것보다 적은 데이터/자원으로 효율적인 학습 가능
- **Decoder 모델 파인튜닝 관점**
  - 생성 태스크: 다음 단어 예측 방식 그대로 파인튜닝
  - 분류 태스크: hidden state 위에 새 linear layer를 연결해 분류기로 사용
- **LLaVA(VLM) 파인튜닝 절차**
  1. 사전학습 단계: 텍스트-이미지 간 공통 표현을 공유하도록 학습(전체 모델을 다시 학습하지 않고, 적은 파라미터만 학습해 자원/시간 절감)
  2. Fine-tuning 단계: 특정 작업에 맞춰 표현 공유를 더 강화, 적은 메모리로 효율적 학습
- **실무 예 (ResNet 등 이미지 모델)**: 전체 레이어를 다 학습시키지 않고, 마지막 fc층 + 일부 뒷단 레이어(예: layer4)만 학습하는 **부분 파인튜닝**이 흔히 쓰임 — 앞단(저수준 특징 추출)은 이미 범용적으로 잘 학습돼 있으므로 고정(freeze)하고, 뒷단(태스크 특화 표현)만 갱신
- 적응(adaptation) 방법 전반: 프롬프트, 전이학습, 파인튜닝 모두 파운데이션 모델을 실제 문제에 적용하는 방식들이며, "얼마나 잘 활용하느냐"가 성능의 핵심
