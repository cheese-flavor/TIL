> al, ml, dl의 정의
```
al = 주어진 환경/데이터를 인지 학습 추론을 통해 목표 달성 하도록 예측 행동 선택 계획하는 시스템

ml = ai 범주 내에서 데이터로부터 학습하여 목적을 달성하는 접근법
     ml이 아닌 ai 시스템 -> 규칙기반 시스템 / 휴리스틱 기반 최적화 알고리즘

dl = ml 범주 내에서 신경망 함수를 사용한 학습 방법론


ML 순환:  반복적 개선 루프

1. 데이터
   데이터(feature, label)에서 규칙을 학습
   Feature: 특성, 모델이 예측에 사용되는 입력정보 / 예측 판단의 근거
   Label: 목표값, 모델이 예측하는 정답

2. 모델과 가설공간
   학습: 입력 -> 출력 관계를 찾는 과정 / 함수로 표현
   가설공간: 관계를 표현할 수 있는 모든 후보 함수들의 모음
   모델 = 가설공간에 속한 특정 함수

3. 학습 = 주어진 데이터에서 정답을 가장 잘 맞출 수 있도록 모델 규칙 조정하는 과정
   1) 데이터: 입력과 정답 쌍으로 된 모음
   2) 가설공간: 모든 후보 함수들의 집합
   3) 손실함수: 어떤 함수가 더 좋은지 판단하는 척도 / 예측값 - 실제값

1D 피쳐 기반 학습: 피처 하나일때 학습하는 가장 단순한 형태

Income = f* + E (미지의 참 함수 + 측정오차)
Y = f*(X) + E

f(x) 학습의 이유: 예측, 중요특성파악, 해석가능성
```

> 지도학습
```
지도학습 = 정답 라벨이 있는 훈련데이터를 사용해 예측모델 학습
        목표: 새 데이터에서 정확한 예측 수행
특성(x): 예측에 사용되는 설명 변수, F의 input
라벨(y): 맞춰야 하는 정답
오류: 예측값과 라벨의 차이
손실함수 = 예측이 정답에서 얼마나 벗어났는지 / 학습을 통해서 이를 고쳐나감
          분류 -> 교차엔트로피 (범주에 얼마나 확률을 주었는지)

회귀(숫자)
        손실함수: MSE (많이 틀릴수록 손실이 커짐)
                구체적인 오차 크기가 중요할 때, 손실비율 계산시

        회귀설명력: R2 = Label 분산 중 피처로 설명되는 비율
                  모델성능을 직관적으로 비교할때

분류(범주)
        분류정확도: 전체중에 올바르게 맞힌 비율
                  -> 불균형정도에 따라서 좋다고만 x
        혼동행렬: 예측값과 실제 값 사이의 관계 행렬형태로 표현
                TP: 실제양성 / 예측양성
                TN: 실제음성 / 예측음성
                FP: 실제음성 / 예측양성 (오탐)
                FN: 실제양성 / 예측음성 (누락) 

                정밀도: 양성판정 중에 진짜 양성 TP / TP+FP
                재현율: 양성중에 예측양성 TP / TP+FN
                F1-score: 2x 정밀도 * 재현율 / 정밀도 + 재현율

        교차엔트로피: (학습과정을 확인)정답에 준 확률이 높을수록 손실이 작아짐
                    확률이 낮으면 손실이 급격히 커짐
                    손실 - log(정답범주에 준 확률)
        *이산값

오버피팅: 훈련데이터의 우연한 패턴/잡음을 다 학습해서 훈련시에만 성능이 좋은
         표본 의존 불안성: 샘플에 따라 예측이 크게 흔들림
         일반화 실패: 보지못한 데이터 오류가 커짐

오버피팅 -> 모델이 너무 복잡 / 오류까지 학습
언더피팅 -> 모델이 너무 단순 / 중요패턴을 놓침
=> 모델선정 및 교차 검증으로 균형잡기
```

> 테스트 및 검증 
```
훈련오류: 모델을 학습시킨 같은 데이터에 다시 적용해 계산오류
테스트오류: 학습에 쓰지 않은 새 관측치에 대해 모델 적용시 평균예측오류

오버피팅 =  훈련오류가 낮고 테스트 오류가 높음
언더피팅 = 학습 덜 되어서 둘다 크게 나타남


테스트 예측 오류 계산: (이상적케이스: 충분히 큰 별로 테스트 데이터셋) 쉽지않음
    데이터를 나눠 여러번 훈련->평가 반복 ex) 검증셋, k겹 교차검증

검증셋 활용의 경우 테스트 오류를 과대 추정할 수 있음
    학습데이터의 모두를 반영한것이 아니기 떄문에 예측 성능 낮아짐


k-fold 교차검증
- 테스트 오류 추정의 표준적 접근
- 추정치는 모델 선택과 최종모델의 테스트 오류 규모 파악에 활용

k=n이면 Leave-one-out 교차검증(LOOCV)
 -> 검증셋 크기는 1 / K폴드의 학습 검증 구조와 비율이 반대
 = 연산량이 많은것 대비 성능향상이 없어서 K-FOLD 추천

```

```
          특성에 따라 클러스터가 안보이거나 알고리즘마다 결과가 달라짐

K=평균: K 수를 미리 정해 분할
       하나의 데이터가 여러 그룹에 동시에 속할수없음
       모든 데이터를 겹치지 않게 빠짐없이 나눠짐

좋은군집화 = 클러스터 내부 변동이 작은 분할
            클러스터 거리 차이의 합이 최소가 되도록 데이터 나누는것
            -> 그룹안에서 얼마나 모여있는지 기준으로 K개의 그룹 만드는

1. 초기화: 관측치들에 무작위로 클러스터 부여 (여러번 시도 권장)
2. 반복: 중심계산 후 관측치를 가장 가까운 중심에 재할당

중심점과의 평균거리가 계속 줄어들기에 매 반복마다 결과가 좋아짐
최적해를 항상 찾는건 아님 -> 초기값에 따라 지역 최솟값으로 수렴가능

계층적군집
1. n개 관측에 대해 쌍별 비유사도 계산 / 관측치를 하나의 클러스터로 시작
2. i개 클러스터 간 쌍별 비유사도를 모두 계산해 가장 유사한 두클러스터 병합
3. 병합 후 남은 i-1개 클러스터 사이의 새 비유사도를 다시 계산

데이터들이 점차 큰 클러스터로 합쳐지는 과정 -> 매 단계에서 병합 (1개 될때까지)
매 단계에서 거리 계산 -> 데이터수 up 계산량 up

링크의유형(쌍별 거리 중)
single(최소거리) 링크, complete(최대거리) 링크, average(평균거리) 링크
```

>선형회귀
```
선형회귀: 입력 변수와 출력 변수 사이의 관계를 직선 형태로 근사하여 예측
         지도학습의 가장 기초가 되는 접근

단순선형회귀: 한개의 설명변수와 하나의 반응변수 사이의 선형관계 찾는방법
            데이터를 가장 잘 설명하는 직선을 찾아 예측에 활용

            모형가정 Y = B0 + B1X + E
            B0: 절편(x=0일때 y 값)
            B1: 기울기(x가 1단위 증가할때 y의 평균 증가량)
            E: 관측오차
            hat: 추정값을 의미

최소제곱법: 실제 관측값과 예측값의 차이 제곱해 합한 값(RSS)을 최소화하는 방법
           데이터를 가장 잘 설명하는 직선을 찾기 위해 계수 b0, b1을 추정
           잔차: ei = yi- y^   / 예측값: y^i = b^0+b1x1

계수 해석
        절편(intercept)의 coefficient는 기본적인값
        피처마다의 coefficient는 피처의 1단위 증가량에 따른 값
        t-statistic = 두 집단 간 평균차이가 표본의 변동성에 비해 얼마나 큰지
                      이 값이 클수록 평균차이가 통계적으로 유의할 가능성 커짐

유의성검정: 계수의 p-value < 0.0001(<< 0.05) 이므로 통계적으로 유의함
모형적합도: R2 높을수록 1에 가까울수록 좋음 (% = 설명가능성을 말함)


다중선형회귀: 독립변수 여러개 존재할 때 사용, 피처 여러개
            관측오차는 모델이 설명하지 못하는 부분, 오류/잔차가 X

유의점: 테스트 성능 과소평가 가능성 有 / 과적합 문제 -> 검증 및 교차검증 활용
       관찰데이터의 상관관계로 인과관계를 주장하면 안됨 (별개)
       다중공선성 문제 발생 -> 계수해석의 어려움 & 분산증가로 불안정한 추정

```

> 경사하강법
```
손실함수의 간단한 표현: L[%] 
                -> 입력을 출력에 더 잘 매핑할수록 더 작은값 반환하는 스칼라 돌려줌
%^ = argmin[L[%]]
     손실함수를 작게 만드는 파라미터 찾기

선형회귀 학습
등고선: 손실함수 값의 크기 / 밝을수록 손실이 크고, 어두울수록 손실적음


경사하강법: 손실 함수의 값이 줄어드는 방향으로 파라미터를 이동하는 과정
          1. 기울기 계산: 손실함수 파라미터를 편미분 진행 (벡터 형태의 기울기)
          2. 파라미터업뎃: 기울기의 반대방향으로 이동해야 손실함수가 줄어듬

함수에 따른 최적화 난이도
Convex vs Non-convex 최적화 문제
- Convex: 곡선이 항상 u자처럼 아래로 볼록. 위 또는 같은 위치
          2차 미분이 항상 양수이거나 0
- Non-convex: 봉우리 골짜기 오목한 구간이 섞인 모양. 아래에 위치

손실함수 모양에 따라 최적화 난이도 달라짐
- Convex 문제: 전역 최소값이 유일함 -> 쉬움
- Non-convex 문제: 여러개의 지역 최소값 또는 새들(?)점 -> 어려움


경사하강법의 단점: Non-convex -> 지역 최소점에 빠지기 쉬움
                 매 스탭마다 전체 데이터에 대한 미분값 업뎃필요 -> 계산량 up
=> 전체 데이터를 한번에 쓰는 대신, 무작위로 선택한 데이터 샘플 사용

확률적경사하강법(SGD) 특징
- 무작위 샘플 데이터를 활용한 미분으로 경로의 무작위성이 있음
- Local 최소점에 빠질 위험이 상대적으로 적음
- 국소최솟값: 전체데이터가 아닌 일부 배치로 기울기 계산 -> 노이즈 섞임
             노이즈때문에 최소점에서 오히려 빠져나오는데 도움이 됨
```
