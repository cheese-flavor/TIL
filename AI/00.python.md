> 활성화함수
```
입력된 신호를 받아 그 신호를 처리하여 출력 신호를 결정하는 함수 / 스위치
필요이유: 아무리 깊게 여러 층 쌓아도 결국 거대한 선형함수와 다를바가 없음
         활성화 함수는 이런 선형함수를 훨씬 복잡한 패턴을 학습할 수 있게함

대표적인거: Linear=입력값 그대로 출력 / sigmoid: 0과 1사이의 값 출력 / Relu: 0보다 작은값은 0, 0보다 크면 그대로

```

>옵티마이저
```

ADAM: 적응적으로 학습률을 그리는 것이 핵심
      관성을 도입해서 왔다리갔다리

```
