## 문제와 접근

- 크기가 `N × M`인 두 격자의 같은 좌표를 비교
- 값이 같으면 `0`, 다르면 `1` 출력
- 리스트 컴프리헨션으로 각 격자를 입력받은 뒤 이중 반복문 순회
- `range(n)` = 행, `range(m)` = 열
- 별도의 결과 배열 없이 `print(..., end=' ')`로 즉시 출력

## 코드 리뷰

- **정확성** · 격자 입력, 조건 분기, 인덱스 접근, 줄바꿈 모두 적절
- **시간 복잡도** · `O(NM)` (입력과 전체 칸 비교)
- **공간 복잡도** · `O(NM)` (두 입력 격자)
- **선택적 개선** · 한 행의 결과를 리스트에 저장하고 `print(*result)`로 출력하면 줄 끝 공백 제거 가능. 원본 코드에 수정 필요 없음
- **기초 진단 보완** · 직사각형 격자에서 행·열의 범위를 구분하는 연습. 당시 진단 2번은 `n=2, m=3` 전제를 놓쳐 오답으로 제출

## 검증과 회고

- 채점 · 코드트리 정답 처리 (학습자 보고)
- 확인용 반례 · `1×1`, `2×3`, `3×2` 등 정사각형이 아닌 격자
- 오답 사례 · 없음 (첫 제출 코드 정답)
- 별도 로컬 실행 · 기록 없음
- 재풀이 날짜 · 미정 (1주차 복습 시 점검)
