## 문제와 접근

- 연·월·일 입력 후 윤년 및 날짜 유효성 판정, 유효하면 해당 계절 출력
- `year(y)`: 윤년인지 Boolean 반환. 400의 배수는 윤년, 100의 배수는 평년, 4의 배수는 윤년
- `season(m)`: 월에 대응하는 계절 반환
- `check(y, m, d)`: 윤년·평년별 월의 날짜 수 리스트에서 `m-1` 인덱스를 참조해 유효성을 검사하고 계절 또는 `-1` 반환
- 기능을 세 함수로 분리해 책임 구분

## ChatGPT 코드 리뷰

- **정확성** · 윤년 판별, 유효성 및 계절 반환 로직 적절. 코드트리 정답 처리 확인
- **시간 복잡도** · `O(1)` (고정된 조건 검사)
- **공간 복잡도** · `O(1)` (고정 크기 배열)
- **개선 1 — 윤년 판별** · 첫 조건의 `y % 4 == 0 and y % 100 == 0`은 `y % 400 == 0`만으로 충분. `return y % 400 == 0 or (y % 4 == 0 and y % 100 != 0)`로 간결화 가능
- **개선 2 — 중복 배열** · 2월의 날짜 수만 다르므로 기본 배열 하나를 사용한 뒤 윤년이면 `days[1] = 29`로 변경 가능
- **개선 3 — 조건 범위** · 문제의 입력 범위가 보장되지 않는 일반 프로그램이라면 `1 <= m <= 12`, `1 <= d <= days[m-1]` 확인 필요. 현재 코드는 월이 범위 밖이면 IndexError 가능하고 `d <= 0`은 별도 배제하지 않음. 문제의 입력 제약 내에서는 정답
