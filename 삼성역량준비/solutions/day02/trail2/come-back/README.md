## 규칙과 풀이 접근

- 동서남북 이동 명령의 각 거리를 **한 칸씩** 처리하여 시작점 `(0,0)`으로 처음 복귀하는 이동 시점 탐색
- 현재 행·열(`c, r`), 누적 이동 횟수(`sum_dist`), 복귀 여부(`possible`) 관리
- 각 이동 후 좌표가 모두 0인지 검사, 최초 복귀 시 시간 출력; 끝까지 복귀하지 못하면 `-1`
- 시간복잡도 · **O(N + Σdist)** (입력 N개 + 각 명령 거리만큼 한 칸씩 이동; 복귀 시 조기 종료)
- 공간복잡도 · **O(N)** (명령·거리 리스트)

## ChatGPT 리뷰 및 최적화 방향

- 장점 · 모든 중간 좌표를 확인하므로 이동 명령 중간에 원점을 통과하는 경우도 올바르게 판단
- 개선점 · 네 방향별 중복 분기를 방향 벡터 또는 딕셔너리로 통일 가능. `dir`은 Python 내장 함수 이름과 중복되므로 `directions` 등 권장
- **구간 기반 최적화 (학습·미제출)** · 명령 시작 좌표와 종료 좌표 사이에 원점이 있는지 먼저 판정 후, 통과하지 않으면 `c += dc * dist`, `r += dr * dist`로 한 번에 갱신
  - 가로 이동: `c == 0 and r * dr < 0 and abs(r) <= dist`
  - 세로 이동: `r == 0 and c * dc < 0 and abs(c) <= dist`
  - 복귀 시점은 `sum_dist + abs(r)` 또는 `sum_dist + abs(c)`
  - 구간 기반으로 입력하면서 처리할 경우 시간 **O(N)**, 추가 공간 **O(1)** 가능
- 주의 · 끝 좌표가 원점인지 **만** 확인하면 이동 도중 통과를 놓침; 장애물·충돌 같은 중간 이벤트가 있는 시뮬레이션에 단순 구간 이동을 일반화할 수 없음
