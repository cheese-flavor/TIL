## 규칙과 풀이 접근

- 북쪽을 바라보는 `(0, 0)`에서 시작; `F`는 1칸 직진, `L`/`R`은 90도 회전
- 명령 하나당 1초 경과, 최초 원점 복귀 시간 출력; 복귀 없으면 `-1`
- 방향 벡터 `mv = [-1,0, 0,1, 1,0, 0,-1]`, 방향 시작 인덱스 `d ∈ {0,2,4,6}`
- 오른쪽 회전 `(d+2)%8`, 왼쪽 회전 `(d-2)%8`; 직진에서 `mv[d]`와 `mv[d+1]`로 좌표 갱신
- 시간복잡도 · **O(L)** (명령 문자열 길이 L)
- 추가 공간복잡도 · **O(1)** (명령 문자열 자체 제외)

## 오류 원인과 리뷰

1. 최초 코드의 `(d±2)%4`는 방향 인덱스 `0,2,4,6`과 불일치하여 값이 0과 2만 순환. 결합 배열의 방향 시작점은 8을 기준으로 모듈러 연산해야 함.
2. 최초 코드에서 `F`일 때만 `time += 1`을 수행. 실제로 `L`, `R`도 1초씩 소요되므로 회전마다 시간 갱신 필요.
3. 최종 정답 · `%8` 적용 및 `L`/`R` 분기에도 시간 증가. 최초 복귀 이후 `break`와 `possible` 처리는 정상.
4. 선택적 개선(미제출) · `dr = [-1,0,1,0]`, `dc = [0,1,0,-1]`로 분리해 인덱스 `0~3`을 관리하면 회전 `(d±1)%4`로 표현 가능. 제출 원본은 변경하지 않음.
