## 규칙과 풀이 접근

- `N×N` 격자에서 입력 좌표를 순서대로 색칠; 매번 방금 색칠한 칸의 **상하좌우 정확히 3칸** 색칠 여부 판정
- 좌표 입력(1 기반)을 0 기반으로 변환; `space[c][r]`에 방문 상태 표시
- 방향 벡터 `[-1,0, 1,0, 0,-1, 0,1]`을 두 칸 단위로 순회
- 색칠되지 않았거나 범위 밖인 방향을 `stop`으로 집계; `stop == 2`이면 정확히 3개가 불가능하므로 조기 종료
- 출력은 방향 검사 종료 후 **한 번** `count == 3`으로 판정
- 시간복잡도 · **O(N² + M)** (격자 초기화 및 M번 고정 4방향 검사)
- 공간복잡도 · **O(N² + M)** (격자 및 입력 좌표 리스트)

## 오답 원인 및 코드 리뷰

1. **attempt1.py** · `count >= 3` 사용. 4개가 색칠되어도 1 출력하는 오류 → `count == 3` 필요.
2. **attempt2.py** · 방향 반복문 내부에서 `print(1)` 또는 `print(0)` 수행. 한 좌표에 출력이 누락되거나 중복될 수 있고, 3개 확인 후 남은 방향이 4번째 색칠 칸일 수 있음.
3. **attempt3.py** · `stop == 2` 시 `print(0)` 후 `break`했지만, 반복문 밖에서 다시 0을 출력 → 결과 행 중복. 채팅에서 검토한 형태이며 실제 제출 여부는 미확인.
4. **solution.py** · 출력문을 내부 탐색 밖에 배치하여 중복 제거. 조기 종료는 그대로 유지.
5. 개선점 · 외부 `for i in range(m)`와 내부 `for i in range(0,8,2)`의 변수명 재사용을 `d` 등으로 구분하면 가독성 개선. 최종 제출 원본은 변경하지 않음.
