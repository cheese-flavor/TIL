## 학습·기록 흐름

CodeTree에서 문제 확인·채점 → ChatGPT에서 설계·손 추적·반례·풀이 학습 → GitHub TIL에 사용자 제출 코드·리뷰·진도 반영.

- **채팅 하나 = Day 하나**. Day 6부터 14일 집중 일정을 사용하고, Day 1~5 기존 코드와 문서는 그대로 보존.
- 삼성 기출 **83문제** 중 Day 1~5 이전 배정 **15문제**를 제외한 **68문제**를 새로운 일정에 배정. 이전 배정 여부는 정답 여부와 다름.
- 하루 5~6시간 내 대표 기출 1문제는 **실전형 120분**, 나머지 3~4문제는 **시간 제한 동행 학습**. Day 19에는 2문제 총 4시간 모의.
- 풀이 상태는 실제 CodeTree 채점 정답과 도움 후 통과, 부분 구현, 개념 이해, 미해결을 구분. **모든 문제 배정이 모든 문제 정답을 의미하지는 않음**.

## 저장소 관리

- 저장 위치: `삼성역량준비/solutions/dayNN/`. 문제별 풀이 코드·리뷰·진도 기록.
- 기존 `TIL/codetree/` 자동 연동 영역과 독립적으로 관리. 기존 Day 1~5 파일은 임의 변경하지 않음.
- 현재 GitHub 풀이 기록은 Day 1~2까지 확인됨. Day 3~5는 ChatGPT 채팅 진행 이력과 GitHub 반영 수준을 구분하며, 사용자의 정답 확인 없이 임의로 완료 처리하지 않음.
