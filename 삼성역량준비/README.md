# 삼성 SW 역량테스트 준비

Python으로 코드트리 트레일을 연습하고, 기출에서 같은 개념을 적용한다. 첫 실전 목표는 시간 안에 한 문제를 끝까지 구현하고 직접 만든 반례로 검증하는 것이다.

- [4주 수업 계획과 오늘 할 일](PLAN.md)
- [삼성 기출 83문제와 유형별 우선순위](PROBLEMS.md)
- [현재 진도와 복습 기록](PROGRESS.md)
- [ChatGPT에서 이어서 공부하기](CHAT.md)

## 역할 분담

| 도구 | 역할 |
| --- | --- |
| 코드트리 | 트레일 학습, 문제 풀이, 채점 |
| ChatGPT | Python과 알고리즘 설명, 단계별 힌트, 내 코드와 반례 검토 |
| Codex | 계획 및 GitHub 기록 정리, 필요할 때 목록 갱신 |
| GitHub TIL | 기기와 채팅이 바뀌어도 이어갈 수 있도록 진도와 풀이 이력 저장 |

기존 `codetree/`에는 코드트리 제출 이력을 계속 쌓고, 이 폴더에서는 공부 순서, 막힌 이유, 다시 풀 날짜를 기록한다. 채점 후에는 `PROGRESS.md`에 한 줄을 남기고 GitHub에 반영한다. 집에서는 최신 TIL을 받아 `CHAT.md`와 `PROGRESS.md`를 새 채팅에 붙인다. 비공개 자료나 개인정보는 공개 TIL에 올리기 전에 확인한다.
