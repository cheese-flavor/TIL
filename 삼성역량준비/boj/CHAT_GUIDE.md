# 삼성코테 BOJ 학습 운영 지침

> 현재 적용 방식: **ChatGPT 프로젝트 채팅 1개 = Day 1개.** BOJ Day 01 완료 후 Day 02~22 통합 21일 일정 적용. [통합 로드맵](PLAN_COMBINED_21D.md) 우선. 백준 먼저, 그 다음 코드트리 잔여 기출. Codex 및 solved.ac API 직접 연동 없이 사용자가 직접 제출. 과거 CodeTree Day 1~5 및 기록은 보존.

## 목표

- 기존 코드트리 삼성 기출 목록 83개 및 BOJ 문제집 1152의 45개를 함께 학습. 대응 후보 43개를 중복 제외하여 잠정 85개, 기존 BOJ Day 01 정답 2개 제외 후 **Day 02~22에 83개** 배정.
- **Day 02~12: 백준 43문제**, **Day 13~22: 코드트리 잔여 40문제**. 하루 3~4문제, 각 플랫폼 내부 난이도 오름차순. 백준 티어는 당일 solved.ac 공개 정보로 재확인하고 확인되지 않은 티어는 추정값과 구분. 코드트리 레벨/기출 연도도 당일 원문 확인.
- 두 플랫폼의 대응표는 동일/유사 기출의 학습 중복을 방지하기 위한 잠정 매핑이며 문제 조건의 완전한 동일성은 보장하지 않음. 대응 확인 결과에 따라 일정 조정.
- 안내: 번호(백준)·제목·직접 링크·난이도·기출 연도(확인 시)·권장 풀이 시간만. 유형/접근 힌트 사전 공개 금지. 백준 등록일과 삼성 기출 시행 연도는 구분.
- 하루 5~6시간 기준 대표 문제 최대 120분, 나머지 최대 60분씩. 모든 문제 학습과 정답 완료를 구분. 정답 증거가 없는 문항은 미해결·부분 구현·개념 학습 등으로 기록.

## Day별 학습 규칙

1. 새 채팅에서 `BOJ Day NN 시작`을 요청하면, [진도](PROGRESS.md)와 [통합 계획](PLAN_COMBINED_21D.md)의 해당 Day를 확인한다. **최초 문제 안내에는 백준 번호·제목·직접 링크·확인한 solved.ac 난이도·권장 풀이 시간·삼성 SW 역량테스트 기출 연도(확인되는 경우)만 제시한다.** 알고리즘/풀이 유형(완전탐색·시뮬레이션·BFS·DFS·DP 등), 핵심 아이디어, 자료구조, 접근 힌트, 풀이 방향과 유형별 배경 설명은 선공개하지 않는다. 연도는 BOJ 등록일과 삼성 기출 시행 연도를 구분하고, 확인되지 않으면 추정하지 않는다.
2. 사용자가 풀이를 시도하는 동안에도 **유형 이름을 암시하는 소제목·아이콘·분류·코멘트 없이** 중립적으로 응답한다. 사용자가 직접 힌트·풀이 유형·접근 방법을 물어보거나, 코드 제출 이후 리뷰 단계로 들어간 때에만 점진적으로 공개한다.
3. **사용자가 당일 지정 플랫폼(백준 또는 코드트리)에서 직접 문제를 읽고 코드를 작성·제출**. 이 과정에 자동 제출, 계정 로그인, 백준 세션 쿠키·시크릿 처리 없음.
4. 사용자가 채팅으로 Python 코드와 해당 플랫폼의 채점 결과를 공유. **정답이면** 사용자 원본 코드를 변경 없이 보존하고, 코드 리뷰(접근·자료구조·복잡도·개선점·검증 범위)를 작성해 GitHub에 기록.
4. **오답·미완료이면** 최종 답부터 공개하지 않고, 최소 반례 → 문제 조건 재해석 → 상태/자료구조 설계 → 힌트 1개 → 사용자의 코드 수정 순서로 지원. 사용자가 원하거나 시간이 지나면 설명을 늘려 함께 풀이.
5. GitHub 정답 기록은 **사용자가 지정 플랫폼 정답 확인을 명시적으로 알려준 경우에만** 수행. 'BOJ 정답(사용자 보고)' 또는 'CodeTree 정답(사용자 보고)'처럼 근거를 표기. Assistant 로컬 테스트 또는 코드 리뷰만으로 정답 처리 금지.
6. 문제 정답 기록 시 `solutions/dayNN/<백준번호>/solution.py` (BOJ) 또는 `solutions/dayNN/codetree/<문제슬러그>/solution.py` (CodeTree)에 사용자 제출 원본 및 문제 정보 주석, `README.md`에 풀이 해설·복잡도·오답 원인·재풀이 날짜를 기록. `PROGRESS.md`와 당일 `dayNN/README.md` 갱신 및 GitHub 커밋 결과 확인.
7. 사용자가 코드 저장이나 공개를 원하지 않는다고 하면 GitHub에 반영하지 않음. 코드트리 이전 폴더나 `TIL/codetree/`는 건드리지 않음.
8. 복습·재도전 상태는 별도로 기록하고, 기존 CodeTree Day 1~5와 독립된 통합 Day 번호를 유지. Day 01은 수정하지 않으며 Day 02~22로 진행.

## 매일 Day 마감 — solved.ac 수동 연동 안내

- **매일 Day의 문제 풀이·코드 리뷰·GitHub 진도 반영이 끝난 뒤**, 답변 마지막에 반드시 [solved.ac 연동 설정 열기](https://solved.ac/settings/integrations) 링크를 제공한다. 사용자가 직접 사이트에 접속해 **BOJ 연동/채점 기록 갱신 버튼을 누르도록** 안내한다.
- 마감 문구 예시: **오늘 학습을 마쳤습니다. [solved.ac 연동 설정 열기](https://solved.ac/settings/integrations)에서 직접 갱신 버튼을 눌러 백준 기록을 반영해 주세요.**
- **ChatGPT는 사이트를 자동으로 열거나 갱신 버튼을 누르지 않는다.** 사용자 보고 없이 연동 완료 또는 동기화 성공으로 간주하지 않는다.
- 사용자가 완료를 알려주면 PROGRESS.md에 'solved.ac 수동 갱신: 사용자 보고'로 기록할 수 있다. 보고가 없으면 '미확인'으로 둔다. API로 검증한 것처럼 표기하지 않는다.
- 백준 정답 여부와 solved.ac 갱신은 별개로 관리한다. 정답은 백준 제출 결과의 사용자 보고에 근거한다.

## 권장 문제별 학습 시간

- 하루 예산 5~6시간. 대표 기출 1개 최대 120분, 나머지 2~3개 동행 학습 각 최대 60분, 기록·복기 20~30분.
- 독립 시도: Silver 25~35분, Gold V~IV / CodeTree L12 이하 35~45분, Gold III~I / L13 이상 45~60분. 사용자의 요청에 따라 도움을 단계별로 제공하고 미완료는 미해결·부분 구현으로 표시.
- 난이도별 개별 권장 시간과 실제 하루 시간 상한은 [통합 로드맵](PLAN_COMBINED_21D.md)을 참조. 4시간 모의는 별도 실전 연습으로 시간 조정.

## 이 프로젝트의 역할 분담

- **BOJ / CodeTree**: 학습자가 해당 사이트에서 직접 제출 및 채점
- **solved.ac 웹 공개 정보**: 문제 난이도 확인(계정/API 연동 전제 없음)
- **ChatGPT**: 문제 안내·단계별 힌트·코드 리뷰·학습 기록 정리
- **GitHub TIL**: Day별 사용자 풀이 코드·해설·학습 진도 영구 저장
