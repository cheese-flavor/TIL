# 삼성코테 BOJ 학습 운영 지침

> 현재 적용 방식: **ChatGPT 프로젝트 채팅 1개 = BOJ Day 1개**. Codex 및 solved.ac API 직접 연동은 사용하지 않음. 백준 제출은 학습자가 직접 수행. 이전 CodeTree 학습 자료는 변경하지 않음.

## 목표

- 백준 삼성 SW 역량테스트 기출 후보 **45문제 전체 학습**, 21일(Day 01~21) 기준.
- solved.ac의 공개 난이도를 조회하여 **쉬운 티어부터 어려운 티어로** 진행. 티어는 시점에 따라 바뀌므로 일별 문제 안내 시 확인한 난이도와 확인 시점을 기록.
- 기존 45문제 편성은 **초안**. BOJ 문제집 포함 여부와 문제별 티어를 조회하여 최종 일정을 확정하며 검증되지 않은 등급이나 진도를 확정 사실로 기록하지 않음.
- 삼성 시험 2문제/4시간을 염두에 두고 후반부에 4시간 실전 모의 진행. 초반에는 난이도에 맞게 독립 풀이 시간 상한을 짧게 설정해 전체 학습 범위를 확보.

## Day별 학습 규칙

1. 새 채팅에서 `BOJ Day NN 시작`을 요청하면, [진도](PROGRESS.md)와 당일 계획을 확인하고 백준 문제 번호·제목·직접 링크·현재 solved.ac 난이도·권장 독립 시도 시간을 안내.
2. **사용자가 백준에서 직접 문제를 읽고 코드를 작성·제출**. 이 과정에 자동 제출, 계정 로그인, 백준 세션 쿠키·시크릿 처리 없음.
3. 사용자가 채팅으로 Python 코드와 백준 채점 결과를 공유. **정답이면** 사용자 원본 코드를 변경 없이 보존하고, 코드 리뷰(접근·자료구조·복잡도·개선점·검증 범위)를 작성해 GitHub에 기록.
4. **오답·미완료이면** 최종 답부터 공개하지 않고, 최소 반례 → 문제 조건 재해석 → 상태/자료구조 설계 → 힌트 1개 → 사용자의 코드 수정 순서로 지원. 사용자가 원하거나 시간이 지나면 설명을 늘려 함께 풀이.
5. GitHub 정답 기록은 **사용자가 BOJ 정답 확인을 명시적으로 알려준 경우에만** 수행. 'BOJ 정답(사용자 보고)'처럼 근거를 표기. Assistant 로컬 테스트 또는 코드 리뷰만으로 정답 처리 금지.
6. 문제 정답 기록 시 `solutions/dayNN/<백준번호>/solution.py`에 사용자 제출 원본 및 문제 정보 주석, `README.md`에 풀이 해설·복잡도·오답 원인·재풀이 날짜를 기록. `PROGRESS.md`와 당일 `dayNN/README.md` 갱신 및 GitHub 커밋 결과 확인.
7. 사용자가 코드 저장이나 공개를 원하지 않는다고 하면 GitHub에 반영하지 않음. 코드트리 이전 폴더나 `TIL/codetree/`는 건드리지 않음.
8. 복습·재도전 상태는 별도로 기록하고, Day 번호는 기존 CodeTree Day 1~5와 독립적으로 BOJ Day 01부터 시작.

## 권장 문제별 학습 시간

| 난이도 | 독립 풀이 권장 상한 | 이후 |
| --- | ---: | --- |
| Bronze / Silver | 30~45분 | 반례·도움 후 수정 30~45분 |
| Gold V / IV | 45~75분 | 동행 풀이 45~60분 |
| Gold III / II | 60~90분 | 동행 풀이 60~90분 |
| Gold I 이상 | 90~120분 | 동행 풀이 및 모의 복기 |

위 수치는 학습 권장 시간이며 백준 채점 시간 제한이 아님.

## 이 프로젝트의 역할 분담

- **BOJ**: 학습자가 직접 제출 및 채점
- **solved.ac 웹 공개 정보**: 문제 난이도 확인(계정/API 연동 전제 없음)
- **ChatGPT**: 문제 안내·단계별 힌트·코드 리뷰·학습 기록 정리
- **GitHub TIL**: Day별 사용자 풀이 코드·해설·학습 진도 영구 저장

## 새 채팅 시작 문구

> 삼성코테 백준 과정 BOJ Day 01을 시작하자. GitHub TIL의 `삼성역량준비/boj/CHAT_GUIDE.md`와 `PROGRESS.md`를 먼저 확인하고, 백준 문제 링크와 solved.ac 난이도를 확인해줘. 내가 백준에서 직접 코드를 작성·제출한 뒤 코드와 결과를 공유할게. 오답이면 단계별로 같이 풀고, 정답이면 사용자 제출 원본·코드 리뷰를 GitHub에 커밋해줘. 기존 코드트리 기록은 변경하지 마.
