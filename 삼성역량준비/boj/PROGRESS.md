# BOJ 삼성코테 학습 진도

- 학습 과정: **BOJ Day 01~21**, 백준 삼성 기출 후보 **45문제**를 solved.ac 난이도 오름차순으로 학습
- 현재 상태: **BOJ Day 01 시작 대기**
- 학습 규칙: [CHAT_GUIDE.md](CHAT_GUIDE.md)
- 기출 45문제 목록·정확한 난이도·Day별 배정: BOJ 및 solved.ac 공개 정보 확인 후 확정할 항목
- 백준 채점 정답: **0문제 기록됨** (시작 전, 학습자의 실제 정답 수를 의미하지 않음)
- 확인 방법: 사용자가 직접 제출하고 정답 결과를 채팅에 보고; 기록에는 `BOJ 정답(사용자 보고)`로 명시
- 이전 CodeTree 자료: `삼성역량준비/`의 기존 PLAN/solutions와 `TIL/codetree/` 보존
