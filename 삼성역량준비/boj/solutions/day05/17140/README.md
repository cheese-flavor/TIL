# 17140 이차원 배열과 연산

- [문제](https://www.acmicpc.net/problem/17140)
- 난이도: Gold IV (계획 기준)
- 결과: BOJ 정답(사용자 보고), 독립 채점 검증 미수행
- [solution.py](solution.py): 마지막 채팅 공유본 보존(문제 정보 주석 추가). 실제 제출 원문 미대조. 최종 출력문 수정 여부 미확인.

## 풀이 접근

- R 연산은 행 단위 처리, C 연산은 전치 후 동일한 행 연산을 수행하고 재전치.
- 0을 제외하고 딕셔너리로 등장 횟수 집계.
- items()로 (숫자, 횟수) 쌍을 만들고 sort(key=lambda x: (x[1], x[0]))로 횟수 및 숫자 오름차순 정렬.
- 숫자, 횟수 순서로 펼친 후 처음 100개만 유지. 최대 행 길이까지 0을 채운 후 배열 갱신.
- 0초부터 100초까지 목표 위치 범위 및 목표값 확인. 100초에도 불일치하면 -1.

## 수정 및 복습

- 전치 결과를 반환받아 a에 대입. zip은 가장 짧은 행에 맞춰 잘리므로 0 채우기 이후 전치.
- 초기 리스트 기반의 중복 빈도 계산 제거, 딕셔너리와 다중 정렬 기준 활용.
- r, c = r-1, c-1로 인덱스 변환.
- 목표값 검사를 시간 제한 검사보다 먼저 수행하여 정확히 100초인 정답도 포함.
- 마지막 공유본의 출력문은 범위를 벗어난 목표 좌표에 다시 접근할 위험이 있음. 최종 권장 수정은 마지막 if/else 전체를 print(time)으로 교체하는 것. 실제 제출에 적용했는지는 미확인.
- 원본 주석의 '내림차순', 길이 '< 100'은 각각 오름차순, 길이 100 초과 시 절단으로 정정 필요. 구현은 올바른 기준 사용.

## 복잡도

- 최대 행/열 길이를 S(100), 연산 횟수를 T(100)라 할 때, 빈도 집계와 패딩 O(S²), 행별 정렬 O(S² log S) 상한.
- 전체 시간 O(T S² log S), 공간 O(S²).

## 검증용 반례 (기대값, 실행 미검증)

초기 배열: 1 2 1 / 2 1 3 / 3 3 3

- 목표 1 2 2 → 0 (초기 상태에서 일치).
- 목표 1 2 1 → 1 (R 연산).
- 목표 1 2 3 → 2 (C 연산 포함).
- 목표 1 2 100 → -1 (시간 초과).
- 목표 좌표가 현재 배열 밖인 경우에도 범위 검사 후 접근할 것.

재풀이 날짜: 미정. 다중 정렬 및 전치 복습 권장.
