# 20055. 컨베이어 벨트 위의 로봇

- [문제](https://www.acmicpc.net/problem/20055) · Gold V (계획 기준) · 2020년 (CodeTree 대응 기준)
- 채점: **BOJ 정답(사용자 보고)**, 2026-11-25. 독립 검증 미수행.
- [마지막 전체 공유 원본](draft.py): 회전 연산 오류 포함.
- [정리 풀이](solution.py): 마지막 전체 공유 코드에 [pop()] + 리스트 회전 수정 안내 반영. 실제 제출 원문 미대조.
- 접근: 내구도 2N칸 및 로봇 위치 N칸 분리. 단계마다 벨트 회전 → 하차 처리 → 뒤쪽부터 로봇 이동 및 하차 → 로봇 올리기 → 종료 조건 확인. 내구도 0 도달 시 stop 증가.
- 오류 교정: 중첩 리스트 초기화, pop의 반환값과 원본 변경, pop 뒤 슬라이싱에 의한 추가 원소 누락, 현재 칸 대신 목적지 i+1 내구도 확인 및 차감. 첫 단계도 회전부터 수행.
- 불변식: 하차 위치는 항상 비워지므로 로봇 위치 리스트의 마지막 0을 앞으로 옮겨도 정상. 회전 직후 0번 칸이 비어 있으므로 이동 반복문에서 0번 제외 가능.
- 복잡도: 종료 단계 T 기준 시간 O(TN), 공간 O(N). stop 누적 관리로 매 단계 전체 내구도 재계수 불필요.
- 반례(논리 검토, 실행 미수행): 입력 `3 3\n1 1 1 1 1 1`, 기대 출력 2. 현재 칸 내구도 0이어도 목적지 내구도가 양수이면 이동 가능. 리스트 [1,2,3,4,5,6]에서 [belt.pop()] + belt[:-1]은 [6,1,2,3,4]가 되어 길이가 감소.
- 재풀이: 슬라이싱과 pop/insert 차이, 하차 처리 시점 복습. 날짜 미정.
