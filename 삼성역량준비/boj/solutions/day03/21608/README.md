# 21608. 상어 초등학교

- [문제](https://www.acmicpc.net/problem/21608) · Gold V (계획 기준) · 2021년 (CodeTree 대응 기준)
- 채점: **BOJ 정답(사용자 보고)**, 2026-11-26. 독립 채점 검증 미수행.
- [마지막 공유 원본](draft.py): fianl_room 오타 포함.
- [정리 풀이](solution.py): 오타 수정 안내만 반영. 실제 제출 원문 미대조.
- [복습용 개선 코드](solution_improved.py): 별도 채점 및 실행 검증 미수행. 사용자 재구현 없이 코드 리뷰만 진행.
- 접근: 배치된 선호 학생 주변 빈칸 점수 갱신 → 최대 선호 점수인 빈자리 후보 추출 → 주변 빈자리 수 및 행·열 우선순위 비교 → 모든 배치 후 만족도 합산.
- 오류 교정: 이미 점유된 칸 제외, 단일 후보 배치 후 break 대신 continue, 변수명 오타, b_score를 -1로 초기화해 빈칸 점수가 모두 0인 경우 대응, 만족도 참조 배열 및 0명 예외·10**(cnt-1) 적용.
- 반례(논리 검토): N=3 빈 교실 첫 학생은 (1,1), N=5도 첫 학생은 행·열 동점 규칙으로 (1,1) (0-based). 선호 학생 미배치 시 점유 칸도 점수 0이므로 후보에서 제외 필요. 남은 후보가 모두 인접 빈칸 0이면 b_score=0, b_seat=[] 초기화 시 IndexError 가능.
- 복잡도: 기존 배치 O(N⁴), 만족도 O(N⁴), 공간 O(N²). 개선 배치 O(N⁴), 만족도 O(N²), 공간 O(N²).
- 개선 포인트: 딕셔너리·집합, 튜플의 사전식 비교, 행·열 오름차순 순회와 엄격한 > 갱신으로 동점 유지, 점수 배열 인덱싱.
- 재풀이: 개선 코드 훑어보기 위주, 날짜 미정.
