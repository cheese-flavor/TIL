# 15686. 치킨 배달

- [문제](https://www.acmicpc.net/problem/15686) · Gold V (공개 자료 기준) · 2018년 (CodeTree 대응 기준)
- 채점: **BOJ 정답(사용자 보고)**, 2026-11-25. 독립 채점 검증 미수행.
- [마지막 공유 원본](draft.py): DFS 호출 인자 i 오류 포함.
- [정리 풀이](solution.py): 안내한 i → m 수정만 반영한 코드. 실제 정답 제출 원문 미대조.
- 접근: 집·치킨집 좌표 분리 → DFS로 정확히 M개 조합 생성 → 조합마다 각 집의 최소 맨해튼 거리 합산 → 최솟값.
- 핵심: 치킨집을 추가하면 각 집의 최소 거리가 증가하지 않으므로 정확히 M개인 조합만 검사해도 최적해 존재. start는 다음 인덱스 i+1로 전달. append/pop 시 종료 조건에서 리스트 복사.
- 오류 교정: 치킨집 좌표 저장 대상, 중복 조합, 리스트 참조, 조합/집/치킨집 반복문 순서, 거리 합 초기값 0, 최종 DFS 인자 i → m.
- 복잡도: C=치킨집 수, H=집 수, M=선택 수. 시간 O(N² + 2^C + C·2^C + binom(C,M)·H·M) 상한, 저장 공간 O(N² + H + C + binom(C,M)·M), 재귀 보조 공간 O(M). 조합 평가를 DFS 종료 시 수행하면 조합 저장 공간 제거 가능.
- 반례(논리 검토, 실행 미수행): 입력 `3 1\n1 2 0\n0 0 0\n0 0 2` 기대 출력 1. 이전 i 인자 호출은 2개 선택하므로 이 경우 결과는 우연히 동일. 입력 `3 1\n1 2 0\n0 0 0\n0 0 0` 기대 출력 1, i 인자 호출은 조합 미생성으로 inf.
- 재풀이: 조합을 직접 저장하지 않고 DFS 종료 시 평가하는 방식 복습 권장. 날짜 미정.
