## 학습 요점

- DFS 분기: 독립 if와 elif 구분, 재귀 호출 후 원래 실행 지점 복귀.
- 조합: start는 탐색 시작 위치, i는 실제 선택 인덱스. append → dfs(i+1, a) → pop.
- 시뮬레이션: 모든 경로 탐색과 단일 경로 이동 구분. 재귀 반환과 반복문의 상태 갱신.
- 연쇄 상태 변경: 접점 비교를 회전 전 수행, 입력 번호와 리스트 인덱스 통일.
- 재풀이 우선순위: 14888 음수 나눗셈, 14889 DFS 직접 작성, 14503 while, 14891 리스트 방식.
