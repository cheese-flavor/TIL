# 14891. 톱니바퀴

- [문제](https://www.acmicpc.net/problem/14891) · Gold V (계획값)
- 채점: 직접 구현 및 리스트 일반화 모두 최종 정답 미확인.
- 직접 구현: 각 명령마다 check12/check23/check34를 회전 전에 저장하고, 중첩 if로 회전 전파. 문자열 '1'로 점수 비교. 마지막 직접 구현은 코드 리뷰상 논리 오류 미발견.
- [리스트 개선 마지막 공유본](draft.py): 수정 안내 전 코드. n 미정의, 오른쪽 접점 시작 오류, 거리 계산 인덱스 혼용.
- 개선: 오른쪽 range(num-1, 3), 회전 방향 abs((num-1)-i)%2==0. 입력 직후 num-=1로 기준 통일 가능.
- 반례: 00100001 / 10000000 / 00000000 / 00000000, 명령 1개 (1 1). 기대 점수 1. 회전 전에 접점을 비교해야 함.
- 시간 O(K), 공간 O(1) (톱니바퀴 4개, 톱니 8개 고정).
- 재풀이: 리스트 수정 후 채점, deque.rotate 비교 선택. 날짜 미정.
