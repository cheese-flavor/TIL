# 14888. 연산자 끼워넣기

- [문제](https://www.acmicpc.net/problem/14888) · Silver I (계획값)
- 채점: 오답 보고 후 수정 안내, 최종 정답 미확인. [마지막 공유 코드](draft.py)는 오답 버전.
- 접근: dfs(idx, value), 남은 연산자 개수 공유. 선택 후 감소, 재귀 호출 후 복원. 독립 if로 모든 가능 분기 탐색.
- 오류: elif는 나머지 분기 생략, 복원 누락, int(value // num[idx])는 음수 내림을 이미 수행.
- 개선: int(value / num[idx]) 또는 value가 음수이면 -(abs(value)//num[idx]) 사용.
- 반례: N=3, 수열 2 9 3, 연산자 0 1 0 1. 정답 최대 -2, 최소 -3. 마지막 오답 코드는 -3, -3. 앞선 대화의 일부 기대 출력 오류를 이 값으로 정정.
- 시간 상한 O(4^(N-1)), 보조 공간 O(N). 실제 완성 경로 수는 연산자 중복을 제외한 다항계수.
- 재풀이: 순열 방식 비교 및 최종 채점 확인. 날짜 미정.
