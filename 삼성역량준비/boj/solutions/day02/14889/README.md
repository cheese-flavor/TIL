# 14889. 스타트와 링크

- [문제](https://www.acmicpc.net/problem/14889) · Silver I (계획값)
- 채점: **BOJ 정답(사용자 보고)**. [정리 풀이](solution.py)는 마지막 사용자 공유 코드 그대로이며 실제 제출 원문 미대조. [공유본](draft.py) 보존.
- 접근: A팀 조합을 DFS로 구성하고 여집합으로 B팀 생성. 실제 선수 번호로 능력치 합산.
- 오류 교정: 매개변수와 global 중복, 정의되지 않은 idx/a, range(n)의 중복 선택, 종료 조건 len(a), 최솟값 초기화, B팀 초기화, player[a[i]][a[j]] 사용.
- 개선: dfs(1, [0])으로 대칭 제거, answer==0이면 조기 종료 가능.
- 반례: 4명, 행렬 0 1 2 3 / 4 0 5 6 / 7 1 0 2 / 3 4 5 0. 기대 출력 0.
- 시간 O(C(N,N/2)·N²), 입력 포함 공간 O(N²), 보조 공간 O(N).
- 재풀이: itertools.combinations와 비교. 날짜 미정.
