# 14503. 로봇 청소기

- [문제](https://www.acmicpc.net/problem/14503) · Gold V (계획값)
- 채점: **BOJ 정답(DFS, 사용자 보고)**. 독립 검증 미수행. [정리 풀이](solution.py)는 채팅에서 안내한 재귀 제한 및 출력 수정 반영본이며 실제 제출 원문 미대조.
- [DFS 마지막 공유본](draft_dfs.py): 출력 부분 NameError 및 재귀 깊이 설정 수정 안내 전 코드.
- [while 마지막 공유본](draft_while.py): nd=(d-1)%4 오류 수정 안내 전 코드. [while 수정본](solution_while.py) 별도 저장, 개별 채점 미확인.
- 접근: 미청소 0, 벽 1, 청소 완료 2. 북동남서 방향 배열, (d-i)%4 반시계 탐색, 이동 불가 시 방향 유지 후진.
- 오류 교정: 연산자 우선순위, 동서 방향, return dfs로 단일 이동 경로 유지, 반환값 출력, 재귀 깊이. while은 매 반복 i를 방향 계산에 반영.
- 반례: 3×4, 시작 (1,1,0), 행렬 1111 / 1001 / 1111. 기대 출력 2, 기존 while은 1.
- 복잡도: 이동 및 검사 반복 횟수 T 기준 O(T) 시간, while 보조 공간 O(1), 재귀 보조 공간 O(T), 격자 O(NM).
- 재풀이: while 방식 복습, DFS 제출 원문 대조. 날짜 미정.
