# BOJ 14501 — 퇴사

- 문제: [백준 14501번 퇴사](https://www.acmicpc.net/problem/14501)
- 학습일: 2026-11-24, BOJ Day 01
- 참고 난이도: Silver III (당일 공개 자료 기준, solved.ac 실시간 티어 미검증)
- 권장 독립 풀이: 40~45분 (실제 소요 시간 미기록)
- 제출 코드: [solution.py](solution.py) — 사용자 공유 최종 코드 원본 보존
- 결과: **BOJ 정답(사용자 보고)**. 사용자가 제출 완료를 명시. 독립 채점 검증 미수행.

## 풀이 접근

- 0 기반 날짜 인덱스 사용. T[day]는 상담 기간, P[day]는 상담 수익.
- 재귀 상태 dfs(day, profit): 다음으로 검토할 날짜와 지금까지 확정한 수익.
- day == N이면 누적 수익을 최대값에 반영한 후 return.
- 상담 선택: day + T[day] <= N인 경우에만 상담 종료 시점으로 이동하며 P[day] 누적.
- 상담 미선택: 상담 가능 여부와 관계없이 다음 날짜로 이동, 수익 유지.
- 두 분기는 독립적으로 실행. 정수형 상태는 호출별로 유지되므로 별도의 복원 연산 불필요.

## 복잡도

- 시간복잡도: O(2^N). 각 날짜의 선택/미선택에 따른 재귀 탐색. N <= 15이므로 충분.
- 공간복잡도: O(N). 입력 리스트 T, P와 재귀 호출 스택. 최악의 날짜 이동 횟수 N, 루트 포함 최대 N+1개 호출 프레임.

## 학습 중 시행착오

1. 입력 반복문의 N/n 대소문자 혼동.
2. 반복문 기반 재귀에서 탐색 시작점 day와 실제 선택 날짜 i 혼동: day + T[i] 대신 실제 선택 날짜 기준 i + T[i] 필요.
3. range(N)으로 매번 처음부터 재탐색하여 이미 지난 상담을 중복 선택하는 문제. 반복문 방식이라면 range(day, N) 사용.
4. day == N에서만 최대값을 갱신하는 반복문 방식은 더 선택할 수 있는 상담 없이 종료되는 경로를 놓침. 해당 방식에서는 유효한 모든 진입 상태에서 최대값 갱신 가능.
5. day를 직접 증감·복원하는 방식에서 상태 의미가 불명확해짐. 계산된 다음 상태를 매개변수로 직접 전달하는 방식으로 변경.
6. 선택/미선택 재귀 방식으로 전환 후 if-else를 사용하여 가능한 상담을 무조건 선택하는 오류 확인. 두 분기를 독립 호출하도록 변경.
7. 수익을 P[T[day]]로 참조한 인덱스 오류 수정: P[day] 사용.
8. 종료 조건에서 return 누락 시 T[N] 접근 오류 가능. return 추가.
9. 퇴사일을 넘는 상담 호출을 막기 위해 day + T[day] <= N 조건으로 가지치기.
10. 최종 제출 통과(사용자 보고).

## 논리 검토용 반례

| 입력(줄바꿈은 /) | 기대 출력 | 확인 사항 |
| --- | ---: | --- |
| 2 / 2 1 / 1 10 | 10 | 실제 선택 날짜 기준 이동 및 동일 상담 중복 방지 |
| 3 / 1 10 / 3 100 / 2 100 | 10 | 마지막 날짜에 상담하지 않아도 수익 갱신 |
| 3 / 2 10 / 1 20 / 1 30 | 50 | 가능한 상담도 건너뛰는 경로 필요 |
| 1 / 1 10 | 10 | 퇴사일 경계와 종료 조건 |
| 1 / 2 10 | 0 | 상담 불가능 시 미선택 경로 |

위 사례는 논리적 검토용이며 별도 실행 또는 BOJ 채점 증거가 아님.

## 개선 방향

- 현재 입력 범위에서는 최적화가 필요하지 않음.
- 향후 날짜별 최대 수익을 저장하는 DP를 이용하여 O(N) 시간, O(N) 공간으로 개선 가능.
- 선택/미선택 재귀와 반복문 기반 재귀의 상태 정의 차이 복습.
