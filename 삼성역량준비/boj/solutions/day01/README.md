## Day 01 학습 메모

- **13458**: 각 시험장에 총감독관 1명 필수. 남은 학생 수가 양수일 때만 부감독관의 몫/나머지 계산.
- 오답 경과: 남은 학생 수 음수 처리 누락 → 음수 처리 분기 위치 오류 → 가장 먼저 양수 여부 검사하여 통과(사용자 보고).
- 제출 코드 원본: [13458/solution.py](13458/solution.py)
- 복잡도: 시간 O(n), 공간 O(n).
- 독립 채점 검증은 수행하지 않았으며 'BOJ 정답(사용자 보고)'로 구분.
- **14501**: 선택·미선택 재귀 탐색, 날짜/수익 상태 전달, 종료 조건과 return, 유효 상담의 가지치기.
- 시행착오: day와 i의 혼동 및 중복 선택 → 상태 직접 수정/복원 → 선택·미선택 분리, 수익 인덱스와 종료 조건 수정 → 상담 종료일 검사 → 정답(사용자 보고).
- 제출 코드 원본: [14501/solution.py](14501/solution.py), [리뷰](14501/README.md). 시간 O(2^N), 공간 O(N).
- 복습 대상: 14501번을 다음 학습 또는 복습 세션에서 힌트 없이 재구현. 재풀이 실제 날짜 미정.
