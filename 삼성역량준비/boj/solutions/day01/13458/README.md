# BOJ 13458 — 시험 감독

- 문제: https://www.acmicpc.net/problem/13458
- 학습일: 2026-11-24, BOJ Day 01
- 난이도: Bronze II (공개 자료 기준, solved.ac 실시간 등급 미검증)
- 원본 코드: [solution.py](solution.py) (사용자가 공유한 최종 제출 원본을 수정 없이 보존)
- 채점 결과: **BOJ 정답(사용자 보고)**. 사용자 본인이 통과를 명시. 어시스턴트가 채점 결과를 독립 검증하지는 않음.

## 풀이 접근

1. 각 시험장에 총감독관이 반드시 1명씩 있으므로 총감독관 수 n명을 기본으로 확보.
2. 시험장 인원 A가 B 이하이면 부감독관이 불필요하므로 계산 생략.
3. A - B > 0이면 남은 학생 수를 부감독관 한 명의 담당 인원 C로 나눈 몫을 더함.
4. 나머지가 있으면 부감독관 1명 추가. 최종 부감독관 수 + n을 출력.

## 복잡도

- 시간: **O(n)** — 시험장 n곳을 한 번 순회.
- 공간: **O(n)** — 시험장별 학생 수 목록 저장. 반복문 자체의 추가 공간은 O(1).

## 오답 원인과 수정

- 1차: 총감독관이 학생 전체를 감당하는 경우, 남은 학생 수가 음수가 되어 부감독관 수를 잘못 계산.
- 2차: 음수 검사 위치를 else 내부로 설정. Python의 음수 나머지 연산 결과가 양수가 될 수 있어 앞의 if 분기에서 잘못 계산.
- 최종: 남은 학생 수가 0 이하이면 먼저 continue로 처리하고, 양수에 대해서만 부감독관 몫과 나머지를 계산. 사용자가 백준 정답 통과를 보고.

## 검토용 반례 및 기대값

| 입력(줄바꿈은 /) | 예상 답 | 목적 |
| --- | ---: | --- |
| 1 / 1 / 2 1 | 1 | 총감독관만 필요한 경우 |
| 1 / 1 / 5 3 | 1 | 음수 나눗셈과 나머지 연산 경계 |
| 1 / 6 / 2 2 | 3 | 남은 학생 수가 C로 나누어떨어짐 |
| 1 / 7 / 2 2 | 4 | 부감독관 1명 올림 필요 |

위 표는 설명을 위한 논리 검토 사례이며 독립 채점 근거는 아님.

## 개선 여지

- 남은 학생 수를 별도 변수로 계산하여 표현을 단순화할 수 있음.
- 남은 학생 수가 양수임을 확인한 뒤 올림 나눗셈 (remaining + c - 1) // c 로 부감독관 수 계산 가능.
- 원본 파일은 수정하지 않음.
