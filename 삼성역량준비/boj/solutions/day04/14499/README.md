# BOJ 14499 — 주사위 굴리기

- 문제: [14499 주사위 굴리기](https://www.acmicpc.net/problem/14499)
- 학습일: 2026-11-27
- 난이도: Gold IV (계획 기준)
- 채점: **BOJ 정답(사용자 보고)**. 실제 제출 원문 및 독립 채점 미검증.
- [마지막 공유 코드](last_shared.py)와 [수정 재구성본](solution.py) 구분. 최종 제출 원문이라고 단정하지 않음.

## 풀이 접근

주사위의 면 ID와 면별 점수를 분리. lr은 윗면·동·아랫면·서, ud는 윗면·남·아랫면·북 순서. 유효한 이동에만 해당 축을 회전하고 다른 축의 공통 윗면/아랫면을 동기화. 이동한 칸이 0이면 아랫면 점수를 복사, 아니면 칸 값을 아랫면에 복사하고 칸을 0으로 변경. 윗면 점수 출력.

## 수정 사항

- [map(...)] 대신 list(map(...))으로 명령 입력.
- 명령 1~4와 방향 배열 인덱스 0~3 일치(d-1).
- 리스트 슬라이스와 정수의 덧셈을 리스트끼리의 연결로 수정.
- 회전 및 점수 교환 로직은 유지.

## 복잡도 및 개선

- 시간 O(NM+K), 공간 O(NM+K), 주사위 상태 O(1). 명령당 O(1).
- 두 축에 공통 면이 존재하므로 항상 윗면·아랫면의 일치 유지. 여섯 면을 단일 리스트에 저장하고 튜플 대입으로 회전하는 대안도 가능.
- 명령을 map으로 직접 순회하는 대안도 가능. 입력 한 줄의 split 비용은 별도 고려.

## 확인용 사례

입력:
```
1 4 0 0 3
0 7 0 0
1 1 1
```
기대 출력:
```
0
0
7
```
첫 이동에서 동쪽 면 ID 3이 바닥으로 이동하여 7을 얻고 세 번째 이동에서 윗면에 도달. 수기 검토 기준, 실제 실행 미수행. 재풀이 날짜 미정.
