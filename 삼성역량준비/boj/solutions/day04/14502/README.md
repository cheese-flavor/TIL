# BOJ 14502 — 연구소

- 문제: [14502 연구소](https://www.acmicpc.net/problem/14502)
- 학습일: 2026-11-27
- 난이도: Gold IV (계획 기준)
- 채점: **BOJ 정답(사용자 보고)**. 실제 제출 원문 및 독립 채점 미검증.
- [마지막 공유 코드](last_shared.py) 보존. [수정 재구성본](solution.py)은 마지막 리뷰에 따라 안전 영역 순회 대상을 virus_lab으로 수정한 코드이며 실제 제출 원문으로 단정하지 않음.

## 풀이 접근

1. 빈칸과 기존 바이러스 좌표 수집.
2. 조합 DFS(start, w)로 빈칸 중 벽 3개를 중복 없이 선택하고 조합 저장.
3. 조합마다 원본 격자의 각 행 복사, 벽 설치.
4. 기존 바이러스마다 영역 탐색 DFS(r, c) 수행. 인접 빈칸을 2로 변경 후 재귀 호출.
5. 모든 확산이 끝난 격자의 0 개수 합산 및 최댓값 갱신.

## 학습 중 수정

- 벽은 인접할 필요가 없으므로 상하좌우 경로 탐색 대신 빈칸 조합 탐색.
- 비교(==)와 대입(=) 구별, append의 반환값 None 주의.
- i+1로 다음 선택 범위 지정. w+[empty[i]]로 새 리스트를 만들므로 pop 복원 불필요.
- 반복문 내부 return 제거: 하나의 하위 호출 후 종료하지 않고 모든 분기 탐색.
- 바이러스 개수는 확산 깊이와 무관하므로 cnt 종료 조건 제거.
- 격자 값을 2로 변경해 중복 방문 방지. 바이러스 확산 상태는 복원하지 않음.
- lab 대입 대신 행별 복사. 모든 확산 이후 virus_lab의 0을 세어 안전 영역 계산.

## 재귀 복습: return과 종료 조건

- dfs(): 하위 함수가 끝나면 현재 함수의 후속 코드 실행.
- return dfs(): 하위 함수가 끝나면 반환값을 전달하고 현재 함수도 종료. 하위 호출 자체를 중단하지 않음.
- 로봇 청소기(14503)의 단일 상태 전이와 연구소의 전체 분기 탐색 구분.
- 명시적 종료 조건과 암묵적 종료 조건 구분. 조합 DFS는 len(w)==3에서 반환. 영역 DFS는 추가로 방문할 빈칸이 없으면 반복문 종료 후 자연스럽게 반환.
- 재방문 방지는 return이 아니라 방문 상태 또는 격자 값 검사로 수행.

## 복잡도 및 개선

E: 최초 빈칸 수.
- 시간 O(C(E,3) × NM).
- 공간 O(NM + C(E,3)): 원본/복사 격자, 재귀 스택 및 모든 벽 조합 저장.
- 벽 세 개 선택 즉시 확산을 평가하면 조합 저장 공간 제거 가능, 공간 O(NM).
- 사용하지 않는 v_count 제거 가능. 필요하면 itertools.combinations로 조합 생성 가능.

## 확인용 반례

입력:
```
3 3
2 2 0
0 0 0
0 0 0
```
기대 출력: 4. (0,2), (1,0), (1,1)에 벽을 설치하면 추가 확산을 차단하고 남은 빈칸 4개 보존. 빈칸 7개 중 벽 3개를 설치하므로 4가 상한. 수기 검토이며 실행 검증 미수행.

재풀이 권장: 조합 DFS와 영역 DFS를 각각 작성하고 return 사용 조건 및 상태 복원 차이를 복습. 날짜 미정.
