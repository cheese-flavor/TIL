# BOJ 3190 — 뱀

- 문제: [3190 뱀](https://www.acmicpc.net/problem/3190)
- 학습일: 2026-11-27
- 난이도: Gold IV (계획 기준)
- 채점: **BOJ 정답(사용자 보고)**. 실제 제출 원문 및 독립 채점 미검증.
- [마지막 공유 코드](last_shared.py) 보존. [풀이 코드](solution.py)는 마지막 공유 코드의 방향 전환 조건에서 +1을 제거한 재구성본이며 제출 원문으로 단정하지 않음.

## 풀이 접근

머리를 리스트 맨 앞, 꼬리를 맨 뒤에 저장. 매초 이동할 좌표를 계산하여 벽 및 현재 몸과의 충돌을 먼저 검사. 사과가 있으면 제거하고 몸길이를 유지한 채 머리를 추가(기존보다 길이 1 증가), 없으면 머리 추가 후 꼬리 제거. 이동 완료 시각에 회전 명령 적용.

## 학습 중 오류

- 사과 개수 정수 입력, 회전 방향 문자열 분리.
- 사과 좌표 1-based → 0-based 변환.
- 머리 좌표를 중첩 리스트로 추가.
- 먹은 사과 제거, 소비한 방향 명령 제거 및 빈 리스트 검사.
- 이동 후 회전 조건은 time == x. +1 사용 시 한 초 늦게 회전.

## 복잡도 및 개선

T: 종료 시간, K: 사과 수, L: 명령 수. 몸길이는 최대 K+1.
- 시간 O(T(K+1) + L² + K + L): 리스트 충돌 검색, 머리 추가, 사과 검색/제거 및 방향 리스트 pop(0)의 누적 이동 비용.
- 공간 O(K+L+1).
- deque와 몸 좌표/사과 set, 회전 인덱스 또는 dict 사용 시 기대 시간 O(T+K+L).

## 반례

입력: 4 / 0 / 1 / 3 D (각 줄 분리). +1 조건이면 4초, 올바른 조건이면 7초 종료. 수기 추적 기준, 실행 검증 미수행.
재풀이 날짜 미정.
