# 삼성코테 통합 3주 로드맵 — Day 02~22

- 상태: BOJ Day 01 완료(13458·14501, 사용자 정답 보고). 다음 학습 Day 02부터 21일간 새 일정.
- 기준: [백준 삼성 SW 역량 테스트 기출 문제집 1152](https://acmicpc.net/workbook/view/1152) 45개 + [코드트리 삼성 기출 목록](https://www.codetree.ai/ko/frequent-problems) 83개(기존 [목록](../PROBLEMS.md)).
- 2015~2021년의 43개 대응 관계는 제목·문제 내용에 근거한 **기출 대응 추정**이며 플랫폼 간 입력/출력 및 제약이 동일하다는 뜻은 아님. 공식 1:1 대응표 미확인. 백준 3190·5373은 기존 코드트리 83개에서 대응 항목 미확인.
- 합집합 잠정 85개(45+83-43). Day 01 정답 2개를 제외한 83개를 새 21일에 배정. 원래 CodeTree 83개 범위를 커버하고 BOJ 전용 2개도 포함. 대응 확인 결과 변경 시 집계·배정을 갱신하고 누락/중복 검토.
- 백준 43개 먼저(Day 02~12), 이후 코드트리 잔여 40개(Day 13~22). 각 플랫폼 내부 난이도 오름차순, 동률은 번호 또는 연도·슬러그순.
- **백준 티어는 계획용 잠정값**(기존 공개 자료 기준이며 solved.ac 최신 개별 확인 전). 안내 직전 공개 solved.ac 문제별 티어를 검증하고 미학습 문제 순서를 조정한다. CodeTree 레벨/연도는 기존 83개 카탈로그 기준으로 당일 원문과 재대조.
- 연도 표기는 CodeTree 대응 기출의 연도(추정 대응에 근거), BOJ 등록일과 다름. 미확인 연도는 '미확인'.
- 안내는 플랫폼·번호/제목·직접 링크·확인한 난이도·기출 연도·권장 시간만. 유형·접근·태그·힌트 사전 공개 금지.

## 운영 시간

- 하루 3~4문제, 5~6시간 내 학습을 목표. 4문제일 때 대표 1문제 최대 120분, 나머지 각 최대 60분(총 300분) + 복기/기록 20~30분. 필요하면 대표 문제 시간을 줄여 다른 문항 시도 시간을 보장. 표의 문제별 권장 시간은 대표/난도 기준이며 합계가 일일 예산을 넘으면 동행형 60분 상한 적용.
- 독립 시도: Silver 25~35분, Gold V~IV/L12 이하 35~45분, Gold III~I/L13 이상 45~60분. 막히면 요청에 따라 반례→힌트→설계·구현 리뷰. 어려운 문항은 60분 동행형 또는 최대 120분 대표 학습 뒤 미해결/부분 구현으로 기록. 83개 학습 시도와 83개 정답은 구분.
- 4시간 실전 모의는 필요시 2문제 선정, 같은 날 남은 문제 시간과 조정. 자동 제출 없음. 사용자 정답 보고와 검증 근거 분리. Day 종료 시 solved.ac 수동 갱신 링크 제공(코드트리 전환 뒤에도 필요 시 BOJ 기록 갱신).
