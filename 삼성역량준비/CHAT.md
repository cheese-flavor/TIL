# ChatGPT로 이어서 공부하기

1. 새 채팅에 [PLAN.md](PLAN.md)의 오늘 행과 최신 [PROGRESS.md](PROGRESS.md)를 붙인다. 기출 유형이나 다른 문제를 찾을 때는 [PROBLEMS.md](PROBLEMS.md)도 첨부한다.
2. 오늘의 코드트리 문제 링크와 직접 작성한 코드를 보낸다. 페이지를 열 수 없다면 헷갈린 규칙과 제약을 요약하고 실패 입력, 기대 출력, 실제 출력을 함께 보낸다.
3. **문제별 채점 정답과 코드 리뷰가 완료되는 즉시**, GitHub 연결을 통해 `삼성역량준비/solutions/dayNN/트레일또는기출/문제슬러그/`에 `solution.py`(사용자 제출 원본)와 `README.md`(규칙·접근·복잡도·해설·검증)를 기록하고 **그 문제만 별도 커밋**한다. `PROGRESS.md`에도 같은 커밋에서 행을 갱신한다. 저장소 작업이 실패하면 미반영 상태를 명확히 안내한다.
4. 각 Day는 채팅 1개와 대응한다. 새 채팅에서 Day 02를 시작하면 `solutions/day02/`를 만들고 문제별 코드·리뷰·진도를 갱신한다. `solution.py` 첫머리에 Trail·Chapter·Lesson/기출, 문제명, 사이트 URL을 주석으로 적되 제출 실행 코드는 보존한다.
5. 기존 `TIL/codetree/`는 코드트리 연동 영역으로 간주하며 **이번 30일 학습 관리 시 읽기·쓰기·의존 없이** `TIL/삼성역량준비/` 안에서 독립 관리한다. Day 종료 후에는 기초 진단과 학습 회고를 추가하고 다음 Day로 넘어간다.

## 새 채팅에 붙일 요청

> 삼성 SW 역량테스트를 Python으로 준비 중이야. 하루 5~6시간 쓸 수 있어. 첨부한 30일 계획과 진도에서 오늘 Day를 찾아, 지정된 코드트리 트레일을 먼저 풀고 기출 1번으로 넘어가도록 도와줘. 트레일 문제를 안내할 때는 로드맵의 `Trail 번호 · 챕터-레슨 레슨명 · 문제 제목(링크)` 표기를 써줘. 예를 들면 `Trail 1 · 8-2 새로운 2차원 배열의 선언 · 두 개의 격자 비교하기`야. 먼저 기본 트레일과 기출 첫 문제를 풀자. 남은 시간에 추가 트레일과 두 번째 기출을 시도하자. 기출 후보가 세 개면 남은 두 후보 중 오늘의 약점과 맞는 하나를 골라줘.
>
> 먼저 오늘 개념을 작은 입력으로 설명하고 내가 손으로 추적해 볼 질문 하나를 줘. 코드 리뷰에서는 실패를 재현할 작은 반례 하나와 어떤 값부터 달라지는지 알려줘. 힌트는 한 번에 하나씩 주고 전체 풀이 코드는 내가 요청할 때 보여줘.
>
> 끝나면 오늘 푼 문제별 결과, 독립 시도 시간과 전체 시간, 힌트 여부, 실패 원인, 재풀이 날짜를 진도 표에 붙일 형식으로 적어줘. 다음 행동도 하나만 남겨줘.
