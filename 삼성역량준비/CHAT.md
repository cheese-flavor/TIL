# ChatGPT로 삼성코테 Day별 학습 이어가기

## 현재 적용 기준

- **Day 1~5**: 기존 채팅과 이전 [30일 계획](PLAN.md)의 배정·코드·회고 그대로 보존.
- **Day 6~19**: [14일 집중 로드맵](PLAN_14D.md)이 최우선. CodeTree Trail 기본 1문제 + 삼성 기출 4~5문제를 그날의 배정 순서대로 진행.
- **1채팅 = 1 Day**. 최신 [PROGRESS.md](PROGRESS.md)를 먼저 확인하고, 기존 미해결 문제는 별도 기록하되 새 14일 배정과 중복하지 않음.
- 기출 목록과 직접 링크·난도·개념은 [PROBLEMS.md](PROBLEMS.md) 기준. 기출 83개 전체 중 이전 Day 1~5 배정 15개를 제외한 68개를 Day 6~19에 배정.

## 풀이 및 설명 절차

1. Day 시작 시 오늘의 Trail/기출 목록·유형·**문제별 제한 시간** 제시. Trail은 **Trail 번호 · Chapter-Lesson 번호/레슨명 · 문제 제목(직접 링크)** 순서로 안내.
2. 개념을 작은 입력으로 설명하고, 사용자가 직접 손으로 추적할 질문 1개 제공.
3. **실전형 기출(120분):** 문제 파악·설계 후 독립 시도 **최대 60분**. L14 이상은 25~40분부터 막힌 지점을 점검; 나머지는 ChatGPT와 함께 구현·반례 검사.
4. **동행형 기출(40/55분):** 10~20분 독립 시도 후 자료구조·상태 정의·의사코드·함수를 함께 풀며 *왜 이 방법인지* 이해. 시간 종료 시 완료 상태를 정확히 기록.
5. **Day 19 모의:** 2026년 하반기 오전 2문제를 합계 4시간 동안 도움 없이 시도한 뒤 복기. 다른 3문제는 짧은 학습.
6. 코드 리뷰는 작은 반례를 먼저 제시하고 값이 처음 달라지는 지점을 추적. 힌트는 1개씩, 전체 풀이 코드는 사용자가 요청하거나 학습용 동행 풀이 단계에 합의한 경우 제공.
7. 매 문제 종료 시 **사용자 보고/실제 CodeTree 채점 정답, 독립 시도 시간, 전체 시간, 힌트 단계, 반례, 복잡도, 다음 복습 날짜**를 기록. 풀이 코드 원본과 설명용 코드를 구분.

## 새 Day 채팅에서 사용할 요청

> 삼성 SW 역량테스트 2주 집중 학습의 **Day 06**을 시작하자. GitHub `cheese-flavor/TIL`의 `삼성역량준비/PLAN_14D.md`와 `PROGRESS.md`를 먼저 확인해줘. Day 1~5는 변경하지 않아. 채팅 하나가 Day 하나야. Trail 기본 1문제를 정확한 Trail/Chapter/Lesson/링크와 함께 안내한 다음, 배정된 기출을 순서대로 진행해줘. 기출 대표 1문제는 120분 실전형, 나머지는 문서의 40분 또는 55분 동행형 상한을 적용해줘. 내가 정답을 완성하지 못하면 정답만 알려주지 말고 왜 이 방법을 사용하는지, 상태 정의·반례·복잡도를 함께 이해하도록 도와줘. 문제별 코드 리뷰 후 GitHub의 dayNN 폴더와 진도를 반영하되 커밋 성공 여부를 확인해줘.

## GitHub 저장·커밋 규칙

1. Day별 경로: `삼성역량준비/solutions/dayNN/trail번호/문제슬러그/` 또는 `dayNN/past/연도/문제슬러그/`.
2. 정답 채점·코드 리뷰가 완료된 문제는 `solution.py`에 **사용자 제출 원본**을 보존하고, `README.md`에 규칙·풀이 이유·시간/공간복잡도·반례·검증 범위를 남김. 오답 시 `attempt1.py` 등 별도 보존.
3. 사용자 풀이 원본의 머리말에 Day/Trail-Chapter-Lesson 또는 기출 연도·레벨, 제목, CodeTree URL 주석을 기록. 실행 본문 임의 수정 금지.
4. 문제마다 변경 내용과 `PROGRESS.md` 업데이트를 별도 커밋. Day 말에는 `dayNN/README.md`에서 그날 배정·정답·부분 구현·오답·복습 계획을 요약.
5. GitHub 반영 실패 시 **미반영**을 명시하고 임의로 저장했다고 말하지 않음. 이전 Day 1~5 파일과 `TIL/codetree/`는 수정하지 않음.
