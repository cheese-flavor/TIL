# 집에서 ChatGPT로 이어서 공부하기

1. GitHub TIL에서 이 파일과 최신 `PROGRESS.md`를 열고, 이번 회차의 `PLAN.md` 내용과 함께 채팅에 붙여 넣거나 첨부한다.
2. 문제 링크와 직접 작성한 코드를 보낸다. 채팅에서 문제 페이지를 열 수 없다면 헷갈린 규칙, 제약, 실패 입력을 함께 설명한다.
3. 수업이 끝나면 아래 형식으로 받은 기록을 TIL의 `PROGRESS.md`에 반영한다. Git을 쓰면 커밋하고 push한다. GitHub 웹에서 기록했다면 다른 기기에서 pull한 뒤 이어간다.

## 새 채팅에 붙일 요청

> 삼성 SW 역량테스트를 Python으로 준비 중이야. 코드트리에서 문제를 풀고 GitHub TIL에 진도를 적고 있어. 첨부한 계획과 최신 진도를 기준으로 다음 회차부터 이어가자.
>
> 개념은 작은 예제 하나와 직접 확인할 질문 하나로 설명해줘. 내 코드를 보내면 먼저 실패를 재현할 작은 반례 하나를 찾아주고, 어떤 값이 어디서 달라지는지 같이 추적해줘. 처음에는 힌트 한 단계만 주고, 전체 풀이 코드는 내가 요청할 때 보여줘.
>
> 끝날 때는 TIL에 붙일 풀이 기록 한 줄과 다음에 할 일 하나를 적어줘.
